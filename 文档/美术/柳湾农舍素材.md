# 柳湾小农舍

柳湾河畔的小农舍，128×104 透明底像素精灵，单件、底边平整接地。**固定俯视微倾、左上受光**：正门朝画面下方，屋顶的前坡与后坡同时入画，墙体只画正面，不画侧立面。低矮的双坡黏土瓦屋顶、浅灰米色的抹泥墙、深暖棕木门；正门偏右，左侧只留一扇木窗。全部由 Python + Pillow 逐像素绘制，无抗锯齿、无半透明边缘。

这张图的重点不是细节密度，而是**骨架要立得住**：屋顶、檐下阴影、墙、门、门槛五层的明度必须各占一档，缩到一倍也分得开。瓦纹与墙面细节保持稀疏，靠大色块组织。

## 结构

坐标从上往下排。整件 120×90，四周留白：上 7、下 7、左右各 4。

| 行 | 部位 |
| --- | --- |
| 7~14 | 后坡（脊线之上的第二坡面，收分 3 像素） |
| 15~17 | 脊瓦：15 亮顶面、16 瓦面、17 脊下阴影 |
| 18~41 | 前坡（沿檐口宽度收分 7 像素的梯形） |
| 42~43 | 檐口板 |
| 44 | 屋檐底沿，一行深线 |
| 45~48 | 檐下遮挡带（45~47 暗、48 过渡） |
| 49~96 | 墙面 |
| 71~94 | 门槛的横向范围 |
| 92~93 / 94~96 | 门槛亮顶面 / 暗立面 |

**屋面。** 前坡是一块上窄下宽的梯形：脊线处每侧收 7 像素，檐口处收 0，逐行线性插值。斜边因此是直线，不是锯齿。后坡只在前坡之上露 8 行，收分压到 3 像素——**收分一陡就成了斜切边，整条后坡会读成一条深色帽檐**，而不是第二个坡面。

瓦纹只做三样：三道通贯的横缝（y=24 / 31 / 38）、每层三四道 2 像素高的瓦口竖缝（错开）、后坡一道缝加三处竖缝。**缝必须连续**——断续的横线在八倍下是划痕，不是瓦。

**檐下。** 屋檐底沿压一行 `#452A17` 的深线定住屋顶，下面四行 `#5C4B36` 的整块暗色，最后一行换 `#7A6A4E` 过渡。没有这条带，屋顶会像贴在墙上；有了它，挑檐的进深就出来了。屋顶比墙面左右各挑出 8 像素，挑出的部分下方是透空的，剪影上一眼能看出檐口。

**墙面。** 整面平涂一个色，只做两件事：右墙角一条 10 像素宽的竖带（墙转过去了），底边三行潮痕（直边）。**不做对角阶梯渐变**——试过按 7 行退 4 像素的阶梯分受光与背光，八倍图上是几道规整的台阶，读成渲染故障而不是光。体积交给屋顶、檐下暗带和墙角带。

墙面细节只有三样，位置互相离开 20 像素以上：三道裂缝（各 4~6 行，各在不同色阶上再压一档）、一块深补块（去角的 4×3）、一块浅补块（4×2）。合计占整件 5.4%。

**门。** 正门偏右：门扇中心在 x=82.5，比画布中线右 19 像素。外框 73~92，立框三像素；门楣 62~64，顶面一行受光、下沿一行压深；门扇 76~89 × 65~91，三块等宽竖板（板缝在 x=80、85），左边缘一列受光、右边缘一列压深，门把是 2×2 的一点暖色高光加暗侧。

门扇上沿压一行暗色，是门楣投下来的影——没有这一行，门扇像是从门楣里长出来的。

**门槛。** 与门框同宽再各宽两像素（71~94）的石板，压在立框下段之上（它在墙面前方，遮住框脚）。亮顶面两行、暗立面三行，两者差 73 个明度，门前因此有一级能一眼认出的台阶。石板与建筑共用同一条底边，**底边平整不被打破**。

**窗。** 左侧一扇，中心 x=36，比中线左 27.5 像素。外框 28~44 × 67~82，框厚两像素；玻璃 30~42 × 69~80，十字窗棂把玻璃分成四格；窗台比窗框各宽一格，同样亮顶面 + 暗立面，与门槛用同一套语言。反光只点左上两格，右下不点——光源才统一。

**轮廓。** 所有与透明相邻的像素取 `#2B2118`，不描黑边。底边因此有一条贯通 104 像素的接地暗线。

## 踩过的坑

**后坡收分太陡 + 太暗，读成帽檐。** 8 行里收 7 像素，又用 `#93552F`，八倍图上是一条带斜切边的深色帽檐，跟「第二个坡面」没关系。改成 8 行只收 3 像素、提亮到 `#9C5A34`，并且只留一道瓦缝——两道缝会把它切成条纹。

**瓦缝做断续，读成划痕。** 第一版每道缝画成 8~16 像素的短段、缝间留 2~3 像素口，想做「斑驳」。八倍图上是一排随机短线，像被刮过。瓦缝是这一层瓦的边界，必须整道贯通；稀疏靠**少画几层**，不靠把线打断。

**墙面做对角阶梯渐变，读成渲染故障。** 按「每 7 行受光边界退 4 像素」分两档，八倍图上是四级规整台阶，横在墙面正中。抹泥墙是平的，光只能分出前后两个面：整面一个色，外加右墙角一条竖带。

**墙脚抖一行，读成杂草。** 逐列随机把潮痕上沿抬一行，本意是「别太齐」，结果是墙根长出一排深浅不一的小齿。建筑底边要平，这里必须直。

**门槛与门框同宽，读成基座。** 齐着框画，一眼是门下面的一个台座；各宽出两像素、并且压在框脚之上，才读成门前的一级台阶。

**最低一层的瓦口压在檐口板上。** 竖缝的 2 行正好落进檐口，八倍下像是檐边垂着一排小齿。瓦口统一上移一行。

**檐口板与后坡只差 4 个明度。** 两块面根本不相邻，没必要各占一个色位。合并成一个色，色板从 21 收到 20。

**校验口径把整面墙算成「墙面」，误报「门扇与门框同色」。** 第一版的 `face_lum` 直接按矩形统计墙面，把门、门框、窗全算进去了，于是「门扇 vs 门框」拿到的是同一个均值。修法是：画的时候用 `owner` 记每个像素属于哪个区域，后画的区域把先画的从集合里摘掉；单一色块的比较直接用色板亮度，不用区域均值。

## 校验

`python3 prototype/pixel-farm/house-generate.py --verify` 需 exit 0。断言覆盖：

- 画布 128×104，alpha 只有 0 与 255，色板锁定；
- 整件 116~124 宽、84~92 高；无孤立像素；轮廓一圈全是最深色；
- **底边一整段**：y=96 上连续 104 像素（12~115），段数 = 1，底边以下 0 像素（入口干净）；
- 明暗阶梯：前坡−后坡 ≥20、墙−檐下 ≥40、门槛顶−门槛立面 ≥30、墙−门扇 ≥60、门扇−门框 ≥15、墙−墙角带 ≥15；
- 正门中心在中线右侧 ≥8 像素，窗中心在中线左侧 ≥8 像素；
- 窗只有一处连通块（一扇窗）；
- 屋面用色 ≤4 种、墙面用色 ≤4 种（大色块没被切碎）；
- 细节（瓦缝、瓦口、裂缝、补块）占整件 1.2%~7.5%；门扇上不得有装饰像素；
- 锚点 `(64, 96)`。

## 接入

锚点 `(64, 96)`，接地行 96，整件 120×90，约合 3.75×2.8 个 32 像素地格；墙面高 48 像素，正好一格半。地面投影由游戏绘制，素材里不烘焙。

底边是一条完整的直线（12~115），可以直接压在一排地砖上；门前 7 行（97~103）全透明，给入口留位置，门槛石板已经把入口标出来。与垂柳同场时，房子比树矮、比树宽，见 `house-cottage-field-2x.png`。

农舍已用于柳湾的田记所旧址，正门朝画面下方。场景投影由 `depth-generate.py` 读取此素材生成。

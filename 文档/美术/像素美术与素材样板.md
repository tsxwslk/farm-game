# 像素美术与素材标准

当前样板：[柳湾光影田畦](../../prototype/pixel-farm/index.html)。普通作物统一 64 源像素株距与行距，保留物种特征优先。旧几何像素、尺寸/间距实验页已经清理，以下保留已确认结论与星露谷核查记录。

## 已确认规格

| 对象 | 源像素规格 | 约定 |
| --- | --- | --- |
| 基础地格 | 32×32 | 程序纹理、连接和过渡 |
| 普通作物种植单元 | 64×64 | 占 2×2 基础地格，播种与收获各一次 |
| 白菜田间成熟图 | 48×72 | 根部锚点 `(24,66)`，根部在种植单元内 `(32,54)` |
| 人物比例占位 | 40×80 | 脚底 `(20,76)`，最终角色仍待制作 |
| 小屋比例占位 | 128×104 | 地基锚点 `(64,94)` |

所有像素数均指源像素，2 倍显示时株行距为 128 CSS 像素。不同物种的可见体型可以不同，小苗不拉满画布，小麦可用一簇代表一份种植作物；树木和建筑按各自占地定义。素材尺寸、逻辑种植单元与通行碰撞分开，不能用 PNG 宽高直接决定碰撞或扣四份种子。

## AI 原图与程序处理

开发者提供成熟大白菜原图，保留于 [source/cabbage-mature.png](../../prototype/pixel-farm/source/cabbage-mature.png)。程序裁去透明留白、保持比例、按已选 16 色无抖动量化、清理半透明边缘，输出已选 48×72。裁切、色板和锚点见 [conversion.json](../../prototype/pixel-farm/source/conversion.json)，[转换器](../../prototype/pixel-farm/convert-cabbage.py)可逐像素重建现有定稿。

16 色是这株白菜的处理参数，不是整个游戏只能用 16 色。后续 AI 图必须统一视角、比例和光源；像素化本身不能保证不同物种或生长阶段风格一致。植株通过轮廓、结构、留白和明暗辨认，颜色作为辅助，避免只换色表示不同物种。生长阶段保持根部锚点一致，收获物另外紧凑构图。

地面由程序生成原生像素素材，场景通过整数倍率与点采样保持清晰。通过灰度、实际尺寸、密植和混种检查辨识度。当前采用河畔青绿与光影田畦，详见[地面套件](程序地面套件.md)及[场景标准](轻量立体感试作.md)。

## 星露谷本地核查结论

只读核查了本机 Steam 安装的 XNB 素材与绘制相关程序集；以下描述该安装版本，不代表所有平台和后续版本。

- 使用 MonoGame 与 xTile，图像、地图、人物、树木、作物分别组织，XNB 是打包格式。
- 地图图集基础格 16×16，`pixelZoom = 4`、`tileSize = 64`；基础世界按四倍绘制，用户缩放继续影响显示大小。
- 世界绘制使用 `SamplerState.PointClamp`，保留像素边缘；参考 [MonoGame 采样说明](https://docs.monogame.net/articles/tutorials/building_2d_games/18_texture_sampling/index.html)。
- 春季户外图集 400×1264，作物 256×1024，Abigail 人物 64×448，春季树木 144×160；整张图集尺寸不等于单物体大小。
- Farm 地图 80×65 格，有 Back、Buildings、Paths、Front、AlwaysFront 等层。前景遮挡和脚底排序提供深度感，镜头主要跟随、平移和缩放。
- 人物方向/动作和作物阶段预先绘制，运行时选择取图区域；耕地按相邻格掩码选择边缘和内部贴图。

本项目只借鉴组织和渲染方法。当前资源来自原创程序绘图或开发者提供的 AI 图，没有复制该游戏的图像、地图或代码。

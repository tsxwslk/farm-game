# 柳湾河岸素材

裸土与河面之间的一整套过渡地砖，32×32 源像素、固定左上受光。三种形状：直边、土岬外凸、水湾内凹，各 3 个变体。全部由 Python + Pillow 逐像素生成，没有手绘、没有抗锯齿。

两岸的材质都不是重画的：土侧**直接调用** [裸土生成器](../../prototype/pixel-farm/soil-generate.py) 的 `build()` 取原块（同色板、同土粒半径、同左上受光），水侧只用 [河面生成器](../../prototype/pixel-farm/water-generate.py) 的主色。过渡砖因此和两侧原块同源。

岸线是受约束的随机游走：相邻列最多差 1 像素、振幅 ±2、**两端强制回到 0**。两端归零不是概率而是保证——直边砖左右相接时岸线才连得成一条，中间又有自然起伏。

## 色板

八色，全部锁死。土用裸土那三色，水用河面主色，中间只插潮土两色与浅青两色：

| 用途 | 色值 | 亮度 | 占比（直边变体 0） |
| --- | --- | --- | --- |
| 裸土铺底 | `#F0B035` | 178 | 35.6% |
| 土粒受光 | `#F9C856` | 202 | 1.1% |
| 土粒暗部 | `#D9921E` | 154 | 6.3% |
| 半湿土 | `#C07A20` | 133 | 3.1% |
| 贴水潮土 | `#8D5412` | 94 | 3.1% |
| 贴岸浅青 | `#ADD1C2` | 197 | 3.1% |
| 次浅青 | `#93C2B1` | 178 | 3.1% |
| 河面主色 | `#6FAAA6` | 152 | 44.4% |

明度台阶是这张砖的全部信息量，所以每一档之间的差都刻意压得均匀：裸土 178 → 半湿 133 → 潮土 94，水侧 197 → 178 → 152。潮土到浅青之间那 100 的跨度，就是岸线本身——它必须一眼可辨，否则岸就“浮”不起来。

## 土层剖面

从上到下四格，各占 1 像素，加起来是岸线附近的全部过渡：

```
裸土  #F0B035   ← 土粒仍按原块 4~8 像素的尺度撒，贴岸两行被带子盖掉
半湿  #C07A20   1 像素，潮气刚开始往上返
潮土  #8D5412   1 像素，深赭，岸线的那条实线
浅青  #ADD1C2   1 像素，浅滩贴岸
次浅青 #93C2B1  1 像素，接回河面
河面  #6FAAA6
```

四格全部只有 1 像素，整条带子 4 像素 = 一块砖的八分之一。再宽就不叫“潮土”了，会读成一圈描边。

## 三种形状

以土为基准（土在左上），掩码由两个判据组成：`above`（在横岸线之上）与 `left`（在竖岸线之左）。

```
直边：土 = above            土岬：土 = above 且 left      水湾：土 = above 或 left
┌──────────────┐            ┌──────────────┐             ┌──────────────┐
│   土  土  土 │            │   土  土 │ 水 │             │   土  土  土 │
│   土  土  土 │            │   土  土 │ 水 │             │   土  土  土 │
│──────────────│            │──────────┼──│             │──────────────│
│   水  水  水 │            │   水  水 │ 水 │             │   土 │ 水  水 │
│   水  水  水 │            │   水  水 │ 水 │             │   土 │ 水  水 │
└──────────────┘            └──────────────┘             └──────────────┘
```

- **直边**：土 480~505 像素 / 水其余。
- **土岬**：土只剩左上象限（226~257 像素），土的角外凸进水里。
- **水湾**：土包住左上两边（748~777 像素），水的角内凹进岸里。

土岬与水湾互为补集：同一块地形，站位不同看到的是两种角，实际拼图时两者各自只出现一种。

### 怎么拼

顺时针旋转 k×90 度（`rot(im, k)`），和草土过渡砖是同一套约定——**土在哪边，就用哪个旋转量**：

| 想要的效果 | 用哪块 | 旋转 |
| --- | --- | --- |
| 土在上、水在下 | straight | 0 |
| 土在右、水在左 | straight | 1 |
| 土在下、水在上 | straight | 2 |
| 土在左、水在右 | straight | 3 |
| 土岬的东岸（土在左上） | outer | 0 |
| 土岬的南岸（土在右上） | outer | 1 |
| 土岬的西岸（土在右下） | outer | 2 |
| 土岬的北岸（土在左下） | outer | 3 |
| 水塘左上角（土在上、左） | inner | 0 |
| 水塘右上角（土在上、右） | inner | 1 |
| 水塘右下角（土在下、右） | inner | 2 |
| 水塘左下角（土在下、左） | inner | 3 |

注意水塘那四行和草土过渡砖的表是**反过来**的：那张表以草为基准（草在四角外侧），这张以塘为基准（土在四角外侧）。实际拼装时按“土在哪边”查这张表就不会错——`shore-pond-4x.png` 和 `shore-island-4x.png` 就是照这张表拼的，可以直接对照。

## 画法

1. **岸线两端归零。** 随机游走每一步都保证 `|h| ≤ 剩余步数`，所以第 32 列必然是 0。这一步不是调出来的，是算出来的——少一个 clamp，最后几列就会挂在高处，砖与砖之间出现 1~2 像素的错台。
2. **每个变体各走一条岸线。** 三条岸线都两端归零，所以任意两块砖在砖边上都对得上；砖内部各异，长河上才不会每 32 像素重复同一道弯。
3. **带子按“到对岸的步数”上色。** 先 BFS 出每个像素到对侧的最短 4 邻步数：土侧 1 步=潮土、2 步=半湿；水侧 1 步=浅青、2 步=次浅青。直边、土岬、水湾共用这一套规则，转角处带子自动跟着拐弯，也不会出现“按行画带子、一拐弯就断”。
4. **土粒数量按可见面积换算。** 不是先铺满 32×32 再裁切，而是按掩码面积折算簇数（`clods × 面积 / 1024`），所以土岬只占四分之一时，颗粒密度和直边砖是一致的。
5. **水面不铺波纹。** 贴岸是静水，波纹交给河面砖。这条不只是省事：波纹是随机分行距的，两块砖的波纹本来就不对齐，岸砖要是在贴岸处也铺一道，和下面的河面砖相接时会露出半截断纹，比空白更难看。
6. **不画土壁、不画投影。** 岸线贴地，边缘感只由明度台阶交代。加一条 2 像素的土壁会立刻变成“俯视 45° 的断崖”，和整张地图的固定俯视视角打架。

## 校验

```sh
python3 prototype/pixel-farm/shore-generate.py --verify
```

| 判据 | 要求 | 实测 |
| --- | --- | --- |
| 色板锁定 | 不出现九色 | 9 张全部色数 = 8 |
| 两端对齐 | 直边砖第 0 / 31 列的岸线都是 16 | 3 个变体全部 16 / 16 |
| 起伏幅度 | 岸线极差 ≤ 4 | 逐块 14~16 / 15~17，极差 3 |
| 带子错位 | 直边砖逐列：贴水一格深赭、上一格不是干土、三格内有半湿 | 0 列错位 |
| 单块带子连续 | 干土不得直接贴水；潮土的水侧必须是浅青 | 0 处 |
| 跨砖带子连续 | 三张装配图逐像素查同一组规则 | 河 / 塘 / 岛 各 0 处 |
| 颗粒尺度 | 土侧暗部占比在原块 ±50%~160% 内 | 0.106~0.156，原块 0.154 |

最后一项跨砖检查是这套砖唯一能抓住“转错方向”的手段：单块砖自己的带子永远是对的，只有拼起来，干土直接贴到深水才会暴露。草土过渡砖的 `seam_faults` 是同一个思路。

## 调参

| 想要 | 改哪里 |
| --- | --- |
| 岸线更直 / 更碎 | `meander()` 里的 `0.12 / 0.88`（越小越直），`AMP` 改起伏上限 |
| 潮土带更宽 | `build()` 里把半湿的 `d == 2` 放宽到 `d <= 3` |
| 浅滩更亮 / 更暗 | `SHORE['shallow_hi' / 'shallow_lo']`，两色要一起动，别只改一格 |
| 水面也带点波纹 | 把 `build()` 里的 `Image.new(..., WATER_C)` 换成 `WATER.build(variant)`，只在 `d >= 6` 处保留 |

## 踩过的坑

- **每个变体共用一条岸线。** 第一版三条岸线是同一条序列，单看一块砖很好，横向连排三块立刻看出同一条弯在重复，像花边。改成三条各自走、两端都归零，砖边照样对得上。
- **两端归零不能靠概率。** 只在振幅封顶时回拉是不够的——最后几列可能挂着 ±1，砖与砖之间就出现错台。每一步都保证 `|h| ≤ 剩余步数` 才是算出来的保证。
- **带子不能按行画。** 直边砖上没问题，一进角砖，竖边那侧就只能按列画，两套写法在转角处对不上，出现一格断口。换成 BFS 距离后只有一套规则，转角自动跟着拐。
- **浅青带第一版太淡。** 初稿 `#B6D8C2 / #93C5AB` 和河面波峰 `#8DBBB0` 只差几个色阶，土岛放进水里后浅滩整条糊掉，只剩一条深赭线在“描边”。压到 `#ADD1C2 / #93C2B1` 才既看得出是浅滩，又不至于把土岛圈成光圈。
- **贴岸处不铺波纹。** 试过让岸砖也带两道波，结果它和下面河面砖的波距对不上，接缝处露出半截断纹，比空白更显眼。静水留着反而干净。
- **角上不引入 45° 斜切。** 斜角看着更“自然”，但草土过渡砖那套斜角是为 45° 斜边专门做的，河岸没有斜边需求；土岬和水湾都用 90° 角，才能直接接上直边砖的直角。

# 柳湾草坪素材

柳湾低矮草坪地块，32×32 源像素、四边无缝平铺、固定左上受光。全部由 Python + Pillow 绘制，无抗锯齿、无放大旧贴图。

## 色板

| 用途 | 色值 | 覆盖率 |
| --- | --- | --- |
| 铺底 | `#97BC29` | 89%~91% |
| 叶尖 | `#B7D74C` | 1.3%~1.8% |
| 暗部（草簇） | `#769622` | 7.0%~8.5% |

整张图严格只用这三色，脚本逐个像素统计，出现第四色即校验失败。三色亮度约为 178 / 199 / 141，明暗跨度小，符合「低对比」。

## 画法

1. **安静打底**：整块先用 `#97BC29` 铺满，九成面积是纯色，远看是连续暖绿；细节全部交给稀疏草簇，对应「大面积背景纹理克制，细节优先留给作物和可交互物件」。
2. **草簇母题**：六种手工画的不规则小簇，宽 3~5、高 2~3。每簇 2~3 个错落的叶尖、一条只有 1 像素高的横向叶基、收窄而不对称的叶根。
3. **摆放**：32 像素切 5×5 抖动格，每格一个候选点，最小间距 4.0 像素，取 11 簇。宏观密度均匀，微观不落网格；一半左右做左右镜像，避免同向重复。
4. **受光**：亮尖整簇决定，不逐像素随机。按像素配额点亮（目标 17 像素），于是四个变体的浅嫩绿总量一致，且亮尖只聚在少数几簇里。
5. **草缝暗点**：空隙里补最多 4 个 1 像素暗点，压住大块空白，不形成噪声。
6. **环绕**：所有坐标对 32 取模，跨边的草簇在对面接上，因此四边无缝，不靠镜像或边缘留白。

## 校验

```sh
python3 prototype/pixel-farm/grass-generate.py --verify
```

判据与实测：

| 判据 | 要求 | 实测 |
| --- | --- | --- |
| 三色锁定 | 不出现三色之外的像素 | 4 张全部通过 |
| 无缝 | 左右、上下环绕差值 ≤ 内部最大相邻差值 | 0.00~11.11，内部最大 32.97~62.38 |
| 密度均匀 | 四象限平均亮度差 ≤ 6 | 0.78~2.59 |
| 亮尖占比 | 1.2%~3.2% | 1.3%~1.8% |
| 暗部占比 | 4%~12% | 7.0%~8.5% |

`grass-seam-check-6x.png` 是把变体随机滚动任意像素后拼接：真无缝的砖滚动后依然连贯，一旦有接缝，滚动会把它推进画面内部，肉眼立刻可见。`grass-with-soil-4x.png` 把 2×2 裸土压在草坪上看过渡，两者色温、明度、纹理密度同属一档，草不会抢过土块和物件。

## 调参

改 `grass-generate.py` 里 `CONF` 即可，不用动绘制代码：

- `clumps`：草簇数量，直接决定密度。当前 11 簇（暗部约 8%）；10 更安静，14 开始偏花。
- `gap`：簇心最小间距，调小会让草簇连成片，调大则变成零散点。
- `lit`：参与点亮抽签的簇比例。
- `light_px`：亮尖像素总配额。这是控制「亮」的唯一参数，改它不会影响暗部密度。
- `specks`：零散 1 像素暗点数量。

当前取的是克制档。若觉得地面太素，优先加 `clumps`，不要只加 `light_px`——亮尖一多，草簇就会从「几簇嫩芽」变成「满屏高光」。

## 试错记录（供后续同类素材参考)

- 单根 1 像素竖笔（2~3 像素高）在低覆盖下读成「小木棍／刻度线」，不像草。
- 加横向叶基后，「叶尖 + 横条 + 两只脚」恰好构成 `H`，在 6~16 倍下像字母。
- 三尖梳（`W` 形）是这批里最像草簇的形态；把叶根收窄、去掉对称脚，就同时消掉 `H` 和栅栏感。
- 22 倍下任何 4×3 像素的簇都会读成符号，判断倍率应放在 3~6 倍（游戏内实际显示）上做。
- 参考图（`风格参考.jpg`）的草地是 1 像素高频抖动，风格更繁密；本素材只沿用它的明暗关系（参考实测 `#9FCB02` 底、`#77A200` 暗），不照搬其密度。

# 程序地面套件

当前入口：[柳湾光影田畦](../../prototype/pixel-farm/index.html)。采用开发者已确认的「河畔青绿」。其他配色、独立地面实验页已清理。

## 交付与连接

草地、裸土、踩实土路、干耕地、湿耕地各四个低细节变体，共 20 张原生 32×32 PNG 和一张 128×160 图集。图集行依次为五类材质，列为四个变体。全部由 Python + Pillow 绘制，无抗锯齿或放大旧 16 像素贴图步骤。

运行时按上下左右与四个对角决定透明边界，处理外角、内角和缺口；只给真正的外边缘加一像素边线。干湿土同属耕地，湿度变化不生成内部草缝或土墙。田畦顶面上移 4 源像素，前侧外缘显示薄土壁。

基础地表按 32×32 拼接，状态按 64×64 种植单元管理；一单元的四个基础地格保持同一湿度。当前场景 4 列×3 行，白菜 48×72，根部株行距均为 64。界面保留局部干湿、全干与全湿对照；未连接真实湿度数值或耗水规则。

## 生成与文件

```sh
python prototype/pixel-farm/ground-generate.py
node prototype/pixel-farm/ground-verify.cjs
```

- [生成器](../../prototype/pixel-farm/ground-generate.py)：色板、纹理、人物比例占位。
- [地形逻辑](../../prototype/pixel-farm/ground-engine.js)：掩码、种植单元、当前试验田和拼接诊断数据。
- [绘图](../../prototype/pixel-farm/ground-painter.js)：边界缓存、基础地面和抬高顶面。
- [资源清单](../../prototype/pixel-farm/ground-manifest.json)：材质顺序、图集路径、色板和人物锚点，浏览器脚本版本同源生成。
- [独立素材](../../prototype/pixel-farm/assets/ground/)：20 张纹理、图集和 40×80 人物占位。

校验覆盖 256 种掩码旋转一致性、内角、满连接、实际十二个种植单元命中边界、整单元湿度同步和干湿连接连续性。下一步精修草土过渡、播种小穴和耕作反馈，随后补齐作物阶段。季节天气按[配色提案](季节天气与场景配色方案.md)后续实现。

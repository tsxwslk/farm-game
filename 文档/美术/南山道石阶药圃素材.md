# 南山道 · 废弃石阶药圃

南山道路碑东侧那方废掉的小药圃，64×48 透明像素，**脚点固定在 `(32,43)`**，固定俯视微倾、左上受光。全部由 Aseprite 批处理跑 Lua 脚本逐像素画出，无抗锯齿、无半透明边缘。

它是一方**围合的低矮石框**，不是一堆石头：后排一道两行厚的薄石沿、左右各一条一像素短石、前排三片宽薄石板，中间夹一条裸露的深土。三层高度依次是 27（后沿）→ 29（土面）→ 39（前沿顶面）→ 43（脚点行），所以整件又宽又矮，玩家从前方靠近时先看到前沿，再看到土。

## 图层与尺寸

| 层 | 作用 |
| --- | --- |
| Back stones | 后排薄石沿，断成三段（27 / 27 / 28），中间两道缝 |
| Soil | 土面：y 29~38，比后沿窄一像素，左右各有一行探出 |
| Side stones | 左右各一像素短石，把土面夹住 |
| Front stones | 前排三片石板：4~24、27~39、42~59，顶面两行、立面到 43 |
| Gaps | 石缝：x25 一道细缝，x40~41 一道宽缝（余绪位） |
| Moss | 缝底、后沿两端少量灰绿苔，共 16 像素 |

## 色板

十二色：石五档、土三档、缝一色、苔两色、轮廓一色。

| 用在哪 | 色值 | 亮度 |
| --- | --- | --- |
| 石与土的深褐轮廓 | `#2B2420` | 38 |
| 石板顶面最亮一行 / 顶面 | `#AC9479` `#95806A` | 148 / 129 |
| 顶面前沿 / 立面 / 立面背光 | `#7D6D5D` `#6D5D50` `#54483C` | 110 / 94 / 74 |
| 土面受光 / 土面 / 土块暗面 | `#74573D` `#5E4530` `#44301F` | 89 / 71 / 50 |
| 石缝阴影 | `#1B1512` | 21 |
| 苔 / 苔暗 | `#6E8A56` `#4E6B3C` | 128 / 99 |

土色比同场的灰褐岩石更暖一档（`#5E4530` 对 `#4E3E32`），才读得出"翻过的土"而不是另一块石头。

## 踩过的坑

- **别把土堆成山包。** 第一版让深土从石板后面隆起十几行、上缘做成圆弧，8 倍下是一块面包，压在亮土底色上更像一片焦痕。改成"前后两道石沿夹一条土面"的围合结构，土只占中间，才读成药圃。
- **土面要有面，不要只有色。** 只是平铺 `#5E4530` 时像一块棕色卡纸；加两道短犁沟、几粒嵌进去的小石子、靠前沿一行压暗之后才像翻过的地。
- **后沿不能有立面。** 后排石沿如果和前排一样画出正面，屏幕上会变成"一道矮墙挡在土前"，土被完全遮住。后排只留两行顶面 + 一行投影，土才露得出来。
- **两侧短石宁可一像素。** 土面左右是笔直的竖边时整块像贴上去的板子；补一像素短石把两侧夹住，才读成围合。
- **苔要躲开暗缝。** 苔点最初落在缝隙正中，把留给紫苏余绪的 `#1B1512` 断成两截；现在苔只贴在缝的两侧。
- **脚点行就是最低行。** 与路碑、树桩一致（`waystone (24,43)`、`stump (24,44)` 的底行都等于脚点 y），所以最低一行必须是 43，接地宽 56 像素。

## 场景接入

场景按脚点 `(32,43)` 绘制药圃。可采集时，程序在前沿 `x40~41` 的石缝处绘制紫苏余绪。

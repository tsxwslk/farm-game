# 柳湾裸土素材

柳湾农田裸土地块，32×32 源像素、四边无缝平铺、固定左上受光。裸土为主，另附踩实土路版本。全部由 Python + Pillow 绘制，无抗锯齿、无放大旧贴图。

## 色板

| 用途 | 裸土 | 踩实土路 |
| --- | --- | --- |
| 主色 | `#F0B035` | `#F3B944` |
| 浅金 | `#F9C856` | `#FBCC63` |
| 深赭 | `#D9921E` | `#DDA02B` |

整张图严格只用这三色，脚本会逐个像素统计，出现第四色即校验失败。三色亮度约为 181 / 202 / 154，明暗跨度小，符合「低对比」。

## 画法

1. **平整打底**：整块先用主色铺满，纹理全部交给稀疏土粒，对应「大面积背景纹理克制，细节优先留给作物和可交互物件」。
2. **土粒**：椭圆在环面上采样，横向拉长、纵向压扁（`ry = rx × 0.55~0.85`），得到 4~7 源像素的扁平土屑，轮廓不带直角也不带细尾。
3. **摆放**：32 像素切 6×6 抖动格，每格一个候选点，最小间距 3.4 像素。宏观密度因此均匀，微观不落网格。
4. **受光**：只有约三分之一的土粒把上沿 1~3 像素改成浅金，其余保持深赭，光源方向统一为左上，不做逐像素随机，避免变成「撒粉」。
5. **沙粒**：空隙里补最多 5 个 1 像素点，暗粒为主，压住大块空白。
6. **环绕**：所有坐标对 32 取模，跨边的土粒在对面接上，因此四边无缝，不靠镜像或边缘留白。

## 踩实土路

沿用同一暖金色系，主色浅一档；土粒从 17 颗降到 9 颗、半径收紧、最小间距加大，受光比例从 34% 降到 28%，所以整体更浅、更平、颗粒更少。

## 校验

```sh
python3 prototype/pixel-farm/soil-generate.py --verify
```

判据与实测：

| 判据 | 要求 | 实测 |
| --- | --- | --- |
| 三色锁定 | 不出现三色之外的像素 | 8 张全部通过 |
| 无缝 | 左右、上下环绕差值 ≤ 内部最大相邻差值 | 0.00~4.88，内部最大 24~48 |
| 密度均匀 | 四象限平均亮度差 ≤ 6 | 裸土 0.98~4.50，土路 0.75~1.60 |
| 着色比例 | 记录用 | 裸土 14%~17%，其中浅金 0.8%~1.4%；土路 4%~5% |

`soil-seam-check-6x.png` 是把变体随机滚动任意像素后拼接：真无缝的砖滚动后依然连贯，一旦有接缝，滚动会把它推进画面内部，肉眼立刻可见。

## 调参

改 `soil-generate.py` 里 `CONF` 即可，不用动绘制代码：

- `clods`：土粒数量，直接决定颗粒密度。要更糙的田土就加到 20+，要更光洁就降到 8。
- `rmin` / `rmax`：土粒半径，控制颗粒粗细。
- `gap`：最小间距，调小会出现连片土块。
- `glint`：加受光边的土粒比例，控制左上光的强弱。

当前取的是克制档：裸土 17 颗、浅金只占 1.3% 左右。若后续觉得地面太素，优先加 `clods`，不要加密 `glint`——浅金一多就会散成砂砾感。

## 与现有素材的关系

现有 [程序地面套件](程序地面套件.md) 的「河畔青绿」五类材质（草、裸土、土路、干耕地、湿耕地）继续服务 [柳湾光影田畦](../../prototype/pixel-farm/index.html)。本次暖金赭裸土是新的色系，另存 `assets/soil/`，尚未替换场景里的 `riverside-bare` 与 `riverside-path`。

暖金赭裸土与土路已接入柳湾地图，由 `ground-painter.js` 读取。

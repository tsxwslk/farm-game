# 柳湾地表岩石

农田边、河岸和林缘的普通灰褐岩石，48×48 透明底像素精灵，单件居中、底边接地。**俯视微倾**：上面是一块较亮的顶面，正面是灰褐主面，右下转出一块较暗的断面；三个切面各自成片，切面之间用一条深折线交代转折，不靠渐变堆立体感。全部由 Python + Pillow 逐像素绘制，无抗锯齿、无半透明边缘。

普通岩石与矿点共用同一块岩体：矿点在这块底图上叠加与岩面咬合的彩色凸起，所以正面特意留出一块 17×5 的纯色窗口。

## 色板

七色，全部是同一支冷调灰褐。明度阶梯就是画面的全部立体感来源。

| 用在哪 | 色值 | 亮度 | 说明 |
| --- | --- | --- | --- |
| 顶面后缘 | `#B5B0A4` | 176 | 受光最亮的一行，只走到七成宽 |
| 顶面 | `#948F84` | 143 | 水平切面，比正面高 33 |
| 正面 | `#726E64` | 110 | 灰褐主色，占整件最大面积，也是留给矿物的那块 |
| 石孔 | `#5F5B52` | 91 | 正面崩口与顶面浅凹，零星几点 |
| 右下断面 | `#4F4C44` | 76 | 背光，比正面低 34 |
| 折线 | `#3A3731` | 55 | 顶面压向正面、正面压向断面，兼作底边暗带 |
| 轮廓 | `#2E2B26` | 43 | 整周一圈，不用纯黑 |

轮廓只用这一档深灰，不另描黑边。七色是这张精灵的处理参数，不是全游戏上限。

一开始用的是暖调 `#7A7060` 一系，八倍下整块读成面包——**岩石的灰褐要偏冷**，R 比 B 只高 20 上下，饱和度压低，才不会和麦色、木头混成一类。

## 结构

画布 48×48。三件的包围盒分别为 32×19、30×15、34×18，宽度落在 30~34，高宽比 1.56~2.27，都低于人物和收获箱，放在田边不抢视线。

| 变体 | 包围盒 | 面积 | 顶 / 正 / 断面 | 接地段 |
| --- | --- | --- | --- | --- |
| 0 楔形 | `x 8–39, y 26–44` | 470 | 131 / 277 / 62 | 27 像素，`x 10–36` |
| 1 扁平 | `x 9–38, y 30–44` | 389 | 103 / 215 / 71 | 26 像素，`x 11–36` |
| 2 单峰 | `x 7–40, y 27–44` | 500 | 105 / 323 / 72 | 28 像素，`x 9–36` |

锚点 `(24, 44)`，即接地行的中线。三件的水平偏移都是 0。

正面、顶面、断面三段怎么切：

1. **顶面**：从轮廓顶边到折线那一行，逐列切。
2. **折线**：顶面的最后一行，通宽取最深的折线色。
3. **正面**：折线以下，左界是轮廓，右界是断面的左界。
4. **断面**：右端 `SIDE_OFF` 列。左界随高度逐级左移——贴顶只剩 6 列，落地 8~9 列，暗部压在下半段，读起来是「石头的右下转过去了」。

## 画法

1. **轮廓是多边形，不是逐列剖面。** 顶点连成闭合多边形，按像素中心扫描填充，斜边自然落成 1 像素台阶。第一版用「4~9 列共用同一顶高、段间跳 3 像素」的剖面写，每一段都是长横段，拼起来是圆包；换成多边形后顶边是几段方向不同的直线，才有棱角。
2. **折线是一条横线。** 俯视微倾时，平面上那条前缘在屏幕上就是一条横线。顶面的后缘跟着轮廓起伏，前缘笔直，两个面才分得开——所以这块石头是「顶面在上、正面在下」，不是「上亮下暗一层渐变」。
3. **顶面后缘的亮边只走到七成宽。** 光从左上来，右端已经转离光源，亮边到 68% 就断。整条通宽的亮边会让石头看起来像上了一层糖霜。
4. **断面用一档更深的颜色，不画渐变。** 正面与断面之间是一条 1 像素折线，颜色和顶面折线同一档，读作同一种「转折」。
5. **底边暗带。** 接地行上一行整行压深，岩石落地时是收口的，不是糊在地面上。
6. **轮廓取最深一档。** 与透明相邻的像素统一改写，整周闭合，不描黑边。
7. **矿物窗口。** 正面里找面积最大的纯色矩形，限宽 14~17、限高 5，取最靠中的那块。三件都是 17×5，位置见清单 `window.rect`。窗口里一个装饰像素都不许落。
8. **石孔与裂缝只在窗口之外。** 石孔是一个两像素的崩口加一粒散点，裂缝是三四像素、中间错一格的短划，落在正面下缘。

## 踩过的坑

- **长横段剖面读成面包。** 「4~9 列一级、跳 3 像素」写出来是一条平滑弧线，八倍下就是一整条面包。改成多边形顶点 + 1 像素台阶后才有块状感。
- **等厚的亮带读成糖霜。** 顶面如果按「轮廓往下固定 5 行」切，亮带和轮廓严丝合缝地平行，看起来是刷上去的一层。折线拉成横线、亮边只走七成，才从「带子」变回「面」。
- **折线做成斜线读成切片。** 试过让折线从左上斜到右下，八倍下像一条切开的面包片——平面上的一条边在屏幕上是直的，斜了就不是同一个平面。
- **顶边量化到 2 像素一级，变成金字塔。** 想让台阶更硬，把顶边吸附到偶数行，结果整块读成神庙或金字塔，后来撤回 1 像素台阶。
- **底部向内收成鼓腹，变成派。** 想让侧面更立体，把底边收窄、中段外鼓，结果读成挞皮。接地段保持一整段平直，靠两端斜边自然收起就够。
- **顶面加一档「背光顶色」，用不上。** 顶面只有 3~5 行，右端通常只剩 1~2 行且被折线吃掉，那一档颜色根本没地方落，反而让「色板锁定」判据报错。所以删掉，右端的暗交给轮廓与断面。
- **石孔会凑成一张脸。** 三粒散点落在同一水平带上，八倍下像嘴。改成裂缝先落笔、石孔与裂缝的切比雪夫距离必须大于 2，并且正面只留一粒散点。
- **斑点贴折线读成破损。** 沿用收获箱那次的教训：装饰像素的八邻域必须还是同一块面，并且不能是轮廓——轮廓是最后一步才改写的，所以判据要连「实心且在边界上」一起排除。

## 校验

```sh
python3 prototype/pixel-farm/rock-generate.py --verify
```

| 判据 | 要求 | 实测 |
| --- | --- | --- |
| 色板锁定 | 不出现第 8 色，且七色都用上 | 三件均通过 |
| 透明底 | alpha 只有 0 与 255 | 通过，无半透明像素 |
| 本体宽度 | 30~34 像素 | 32 / 30 / 34 |
| 低矮 | 宽高比 ≥ 1.55 | 1.68 / 2.00 / 1.89 |
| 单件居中 | 水平偏移 ≤ 0.5 像素 | 0.0 |
| 锚点 | `(24, 44)` | 三件一致 |
| 接地清楚 | 最低行只有一段、≥18 像素 | 27 / 26 / 28 像素，各一段 |
| 三个切面都成立 | 顶 ≥100、正 ≥170、断面 ≥45 | 最少的也是 103 / 215 / 62 |
| 明暗阶梯 | 七级单调、每级 ≥8 | 176 / 143 / 110 / 91 / 76 / 55 / 43 |
| 轮廓闭合 | 与透明相邻的像素全是最深一档 | 0 处未取深色 |
| 无孤立像素 | 每个实心像素至少有一个实心邻居 | 0 个 |
| 轮廓不规则 | 镜像必有缺口、顶高 ≥6 种、单跳 ≤3、无超 12 列的平段 | 94 / 33 / 60 处镜像不符，顶高 13 / 7 / 8 种，最长平段 4~6 列 |
| 矿物窗口 | 纯正面色、≥14×4 | 三件均 17×5，`pure=true` |
| 装饰安全 | 石孔贴折线或轮廓 = 0 | 0 处 |
| 装饰克制 | 石孔占面积 0.5%~7% | 1.49% / 1.29% / 0.80% |

「轮廓不规则」这组是这块石头的机器判据：镜像必然对不上（不可能是规则形状），顶边至少有六种高度、单次跳不超过 3 像素、也没有超过 12 列的平段（否则读成板子）。谁把轮廓改回圆包，这组立刻报。

各面亮度只统计面内像素，折线和轮廓是共用的深色，不参与比较。实测顶 149.6~157.8、正 109.7~109.8、断面 76.0，两级落差都在 33 以上。

## 调参

改 `rock-generate.py` 顶部的常量与 `VARIANTS` 即可：

- `poly`：轮廓多边形顶点，顺时针。底边取 `y=45`，像素中心采样才会落到 44 行；左右两端各留一段近垂直的边，收成「削面」而不是圆角。
- `ridge_y`：顶面折线所在行。改小顶面更薄、正面更高；改到接近轮廓顶边，顶面就只剩一条亮边。夹在「顶上方 1 行」与「底上方 3 行」之间。
- `SIDE_OFF`：断面左界随高度的偏移，贴顶 6 列、落地 8 列。整体加 1 断面更宽、正面更窄；改成等差就是斜切，改成同值就是垂直断面。
- 窗口上限写在 `window_rect()` 里（宽 14~17、高 5）。放宽会让正面更空、装饰没地方落；收窄会挤到矿物。
- `PAL`：整条明度阶梯。只改一项会破坏阶梯差，校验会直接报出来。

换石孔与裂缝排布改 `build()` 里的种子；几何、色板和所有断言都不变。

## 接入

- 以底边中心 `(24, 44)` 对齐地格中心，和收获箱同一套锚点。
- 不画投影；落地影由游戏按所在田畦高度补，和耕地前侧土壁用同一套投影色。
- 整件宽 30~34，约一个 32 像素地格宽，摆在田边、河岸与林缘都合适。
- 矿点沿用同一块岩体：把矿物晶簇精灵叠在正面窗口（清单里的 `window.rect`）上，晶簇自己带左上受光，岩体不动。
- 柳湾场景的普通岩石使用 `assets/rock/rock-atlas.png` 的前三帧，旧盐坑使用 `rock-ore-salt.png`。两者的脚点均为 `(24, 44)`。
- 试玩版敲击三次产出一份岩盐，矿点采尽后暂时隐藏，刷新时恢复。裂纹阶段留待后续制作。

## 为什么用程序生成

岩石的形状是「一片不规则多边形 + 三个面」，可以用顶点写出来，程序生成在三个地方更稳：

- **像素网格**：折线、接地行、窗口边界全落在整像素上，缩放后没有半像素糊边。
- **色板**：七色锁定，第八种颜色会被校验拦下；生图做不到逐像素可控。
- **可复现**：改一个顶点重跑，产出逐像素一致；变体只需换一组顶点。

代价是「像不像石头」这件事得靠几何判据兜住，所以才有「顶高 ≥6 种、单跳 ≤3、没有超 12 列平顶、镜像必有缺口」这一组断言。这几条是这块石头最容易被改回「面包」的地方。

# 柳湾木制收获箱

柳湾农田边装收成的木箱，48×48 透明底像素精灵，单件居中、脚底接地。**主视图**：正面正对镜头、左右严格对称，固定俯视微倾，顶面在正面之上沿进深收窄露出。左上受光，顶面最亮、盖沿次亮、箱体中间色、盖沿下与箱底最深。全部由 Python + Pillow 逐像素绘制，没有抗锯齿、没有半透明边缘。

## 文件

放大图、拼接图和验收图由生成器写入仓库根目录的 `output/art-previews/crate/`。

| `crate-harvest-preview.png` | 四格同为 4 倍：浅底一件，草地、干耕地、湿耕地各一件 |
| `crate-manifest.json` | 色板、包围盒与锚点、顶面逐排宽度、各面亮度、接地段、逐项校验结果 |

## 色板

八色，全部取自同一暖木色系。明度阶梯就是画面的全部立体感来源，不靠渐变。

| 用在哪 | 色值 | 亮度 | 说明 |
| --- | --- | --- | --- |
| 顶面 | `#E4AF71` | 184 | 受光最亮，水平的盖板顶面 |
| 顶面木纹 | `#F5CB95` | 209 | 只在顶面点 6 个像素 |
| 盖沿 | `#CD9152` | 156 | 盖板竖直角度的厚度，3 行 |
| 正面木纹 | `#C4874B` | 146 | 比盖沿低半档，避免与盖沿混读 |
| 箱体正面 | `#B37843` | 132 | 中间色，占整件最大面积 |
| 板缝 | `#7D5027` | 89 | 顶面与正面的板缝、板端 |
| 底脚 | `#613C1B` | 67 | 离地面最近，压到最暗 |
| 轮廓 | `#4A2A10` | 49 | 整周一圈，含底脚；不用纯黑 |

轮廓只用这一档深木色，不另描黑边。8 色是这张精灵的处理参数，不是全游戏上限；白菜定稿用的是 16 色。

## 结构

整件 32×30，画布 48×48，左右各留 8、下留 3、上留 15 像素透明。左右留白相等，是"主视图"最直接的体现：包围盒中线与画布中线都在 23.5，水平偏移 0。

| 行 | 内容 |
| --- | --- |
| 15–19 | 顶面，5 行。逐排向里收：宽 32 / 30 / 30 / 28 / 28 |
| 20 | 折线，1 行深色，通宽。把水平的顶面与竖直的盖沿切开 |
| 21–23 | 盖沿，3 行，通宽 32。盖板厚度只由这 3 行交代 |
| 24 | 盖沿下阴影，1 行深色，通宽 |
| 25–41 | 箱体正面，17 行。板缝落在 30、36，分成三块板 |
| 41 | 箱底深线，与上一行同属箱体，读作箱底厚度 |
| 42–44 | 底脚，2 只，各 5 像素宽，`x 10–14` 与 `x 33–37` |

锚点 `(24, 44)`，即两只底脚的最低一行、整件的水平中线。

## 画法

1. **先落三块大色块。** 盖板、箱体、底脚各一个颜色，先不画任何细节。三块的面积比决定了第一眼印象：箱体最大、盖板一条、底脚两只小方块。
2. **顶面向进深收分。** 每排比前一排每侧收进 1 像素，5 排收成 32 / 30 / 30 / 28 / 28。这一收就是"俯视微倾"的全部来源——顶面看起来是往远处退去的，而不是一条贴在箱子顶上的横带。
3. **折线一行把两个面切开。** 顶面是水平的、受光最足；盖沿是竖直的、折过去一档。没有中间这行深色，两者会连成一条 8 行高的亮带，读不出"这是盖子的顶面，那是盖子的厚度"。这一行是整个改动里最关键的一笔。
4. **板缝顺进深走。** 顶面两条板缝把它切成三块板，缝线跟着收分一起往里偏（`x` 16→17、28→28），所以是几乎竖直、略带收敛的两条线，不是上一版的 45° 斜线——45° 是右侧四分之三视角的产物，主视图里板缝该朝灭点收。
5. **箱体正面两道断续板缝。** 每道由 6~11 像素的短段和 2~4 像素的断口组成，不留一条通宽硬线——通宽会读成裂缝。
6. **木纹控制在 85 个像素。** 每块板两笔 2~3 像素短横，顶面 3 笔。全部短、横、稀，方向跟板面一致。
7. **轮廓整圈取最深一档。** 与透明相邻的像素统一改成 `#4A2A10`，底脚也包进去，所以接地点是收口的，不是糊在地面上的。
8. **不画投影。** 物件只交自身的明暗，落地影由游戏按所在田畦高度绘制。

## 为什么没有侧立面

上一版是四分之三视角：顶面朝右上斜切 5 像素，同时在右侧补了 5 像素宽的侧立面，用来给顶面斜边收口。问题出在两者叠加——顶面后缘比正面宽出 5 像素，正面只占整件 33/38，第一眼读起来是"从右前方看过去"，也就是偏右视图。

改成主视图要动的是两处，不是一处：

- **去掉侧立面。** 相机在箱体正中垂直面上时，侧面本来就看不到。省下来的宽度还给正面（33 → 32），左右留白变成各 8 像素、完全相等。
- **顶面改成左右对称收分。** 上一版靠"向右平移"表达进深，那本身就是偏斜的来源。改成每侧各收 1 像素，进深感还在，但左右对称，轮廓不会往任何一侧倒。

顺带保住了一个原始要求：底边保持水平。收分只作用在顶面，箱体与底脚的外框仍是方正的矩形，落地是平的。

原来侧立面承担的两件事换了位置——轮廓闭合交给对称收分（左右两侧各自收口，不再需要第三面接住断口），"背光面用深色"交给折线与盖沿下阴影这两行。主视图里没有背光立面可画，深色就落在两个转折处。

## 校验

```sh
python3 prototype/pixel-farm/crate-generate.py --verify
```

| 判据 | 要求 | 实测 |
| --- | --- | --- |
| 色板锁定 | 不出现第 9 色 | 通过，色数 = 8 |
| 透明底 | alpha 只有 0 与 255 | 通过，无半透明像素 |
| 单件居中 | 水平偏移 ≤ 0.5 像素 | 0.0（包围盒 x 8–39，宽 32） |
| 左右对称 | 轮廓镜像后逐像素重合 | 0 个像素对不上 |
| 接地清楚 | 最低一行是两段等宽底脚 | y=44，`x 10–14` 与 `x 33–37`，共 10 像素 |
| 明暗阶梯 | 顶 > 盖沿 > 正 > 脚，每级 ≥ 8 | 178.4 / 155.1 / 126.3 / 67.3 |
| 轮廓闭合 | 与透明相邻的像素全是最深一档 | 0 处未取深色 |
| 木纹克制 | 木纹像素占物件面积 2%~12% | 85 / 882 = 9.6% |
| 无孤立像素 | 每个实心像素至少有一个实心邻居 | 0 个 |

「左右对称」这条是这次新加的，也是主视图的机器判据：只要有人把侧立面加回来，或者把收分做成单侧平移，镜像对不上的像素数立刻不为 0。

各面亮度只统计面内像素，轮廓那一圈是共用的深色，不参与比较。`crate-harvest-preview.png` 的后三格是验收重点：干耕地的底色 `#A9652C` 与箱体正面 `#B37843` 只差 11 级，能不能分开靠的是顶面、折线与盖沿阴影圈出来的轮廓，而不是正面的色差。

## 调参

改 `crate-generate.py` 顶部的常量即可：

- `W`：正面宽，现为 32。取偶数才能与 48 的画布中线严格对齐，改奇数会让「居中」断言失败。
- `D`：顶面进深行数，现为 5。加到 7 俯视感更强；低于 3 顶面只剩两条缝，读不出是板面。
- `TAPER`：顶面后沿每侧收进多少像素，现为 2。改 0 是纯正视、顶面成一条横带；改 3 收束更急，但 5 行里会出现 3 像素的台阶。
- `H_LID`：盖沿厚度行数，现为 3。低于 2 就只剩一条线，"盖板厚度"读不出来。
- `H_BODY`：箱体高度，现为 17。加到 20 会从"箱子"偏向"柜子"。
- `FOOT_W` / `FOOT_H`：底脚尺寸，现为 5×3。加宽会读成底座而不是脚。
- `PAL`：整条明度阶梯。只改一项会破坏阶梯差，校验会直接报出来。

想换一套木纹排布，改 `build(seed=...)` 的种子；几何、色板和所有断言都不变。

## 接入

- 以脚底中心 `(24, 44)` 对齐地格中心，物件自然站在格子上。
- 不画投影；需要落地影时由游戏按田畦高度补，和耕地前侧土壁用同一套投影色。
- 整件宽 32，正好一个 32 像素地格宽；在 64 像素种植单元里占半格，比白菜（48×72）矮、比人物（40×80）窄，适合摆在田边或屋前。
- 与耕地的关系见 `crate-harvest-preview.png` 第三、四格：干耕地上靠顶面与盖沿阴影分开，湿耕地上底色更深、分得更开。

## 为什么用程序生成而不是生图

这个物件的形状是刚性的：三条边、四个横向分区、三块板。凡是能用坐标写出来的东西，程序生成在三个地方都更稳：

- **像素网格**：顶面 5 行、盖沿 3 行、底脚 3 行、折线 1 行，全部落在整像素上，缩放后不会有半像素糊边。
- **色板**：八色锁定，第九种颜色会被校验拦下；生图做不到逐像素可控。
- **可复现**：改一个常量重跑，产出逐像素一致。

白菜当初用 AI 原图 + 16 色量化，是因为叶球的层层包裹没有可用的几何描述。木箱正好相反。以后若要做"掀开盖子、里面装满作物"的版本，仍是先跑同一套几何，再把作物精灵叠进箱口，不需要重新生图。

# 柳湾水面素材

柳湾河道的开阔水面，32×32 源像素、四边无缝平铺。主色 `#6FAAA6` 的青蓝色淡水，靠稀疏的短横波线与低对比暗纹读出缓流；画面里只有水，不画岸、不画倒影、不画泡沫。全部由 Python + Pillow 逐像素生成，没有抗锯齿、没有放大旧贴图。

## 色板

只有三色，明度差都压在 20 以内——水面的“安静”来自低对比，不是来自低密度。

| 用在哪 | 色值 | 亮度 | 占比（变体 0） |
| --- | --- | --- | --- |
| 主色 | `#6FAAA6` | 152 | 83.5% |
| 波峰亮段 | `#8DBBB0` | 172 | 10.6% |
| 波谷暗段 | `#5E9796` | 134 | 5.9% |

亮段比主色高 20，暗段比主色低 18。这个幅度是刻意的：再高一档，水面会碎成闪点；再低一档，波纹在 3 倍下就看不见了。

## 画法

1. **主色铺满，不铺底纹。** 水面本体是一整片干净的主色，任何“噪点打底”都会让水变脏。
2. **波线按行组织，行距不等。** 每 5~6 行一条波线，行距在 5 与 6 之间随机。等距会读成布纹，这是第一版最明显的毛病。
3. **一条波线由短段与断口交替组成。** 短段 2~5 像素，断口 1~2 像素，一条线沿 x 走满 32 格后从对侧接上。
4. **明暗落在同一条波线上。** 六成短段用亮色（受光波峰），四成用暗色（背光波谷）。这一点是整张图能不能读成水的关键：把亮纹和暗纹当成两套独立的笔画，结果是满地色块；放在同一条线上，才是一条起伏的水线。
5. **波线会缓慢漂移。** 每隔几段，整条线上下挪一格，幅度不超过 ±1，读作缓流的走向。没有漂移时，每条线都像用直尺画的。
6. **三成短段加厚成两行。** 全部等高会变成一叠细条；加厚之后水纹才有厚薄。
7. **四处留白是硬约束。** 落笔前要求上下各一行、左右各一格都是空水。短段可能加厚或漂移，不留这一圈空地，相邻两段会贴成 3×3 的同色块，读成“斑”而不是“纹”。
8. **坐标全部对 32 取模。** 波线跨过砖边后从对侧接上，所以一块砖自身就能无缝平铺。

## 与参考图的关系

参考图（用户提供）是偏密的写法：浅蓝小块按错位的砖格排布，块间夹 1~2 像素暗色，明暗对比更强、覆盖率接近一半。

这张砖按需求里「少量亮波纹、低对比暗纹、保留大面积安静水色」取的是**同一套语言、更低的密度**：主色仍占 83%，亮暗各占一成与半成。要往参考图的密度靠，改 `CONF` 即可（见调参），几何与断言都不用动。3 倍混铺（`water-field-3x.png`）是最接近参考观感的一张——低分辨率下，同样数量的短段会因为缩小而显得更密。

## 校验

```sh
python3 prototype/pixel-farm/water-generate.py --verify
```

| 判据 | 要求 | 实测 |
| --- | --- | --- |
| 色板锁定 | 不出现第四色 | 4 张全部色数 = 3 |
| 四边无缝 | 环绕差值不超过砖内最大相邻差值 | 左右 ≤ 3.77、上下 ≤ 6.09，内部最大 20.09 |
| 四象限均匀 | 亮度差 ≤ 6 | 0.39 ~ 2.85 |
| 边圈均匀 | 边圈与内部均值差 ≤ 3.5 | −0.67 ~ 1.06 |
| 错开排列 | 每条 8 行带至少 3 个亮像素 | 最少 13 个 |
| 无孤立亮点 | 亮像素上下左右都无同伴的数 = 0 | 0 |
| 不糊成斑 | 3×3 同色块 = 0 | 0（2×2 不设限：两行高的短段本来就有） |
| 面积配比 | 亮 5%~16%、暗 3%~14%、主色 ≥ 78% | 亮 7.7%~11.1%、暗 5.9%~8.5%、主色 81.5%~83.8% |

`water-seam-check-6x.png` 比数值更说明问题：四块砖各自随机滚动再拼起来，如果哪条边上有接缝，滚动会把它推到画面内部。这张图里看不到任何接缝线。

## 调参

改 `water-generate.py` 顶部的 `CONF`：

- `row_min` / `row_jitter`：波线行距，现为 5 + 0~1。改成 4 更密（接近参考图），改成 7 更空。
- `seg_len`：短段长度，现为 2~5。加长到 3~8 会读成“横向条纹”，缩短到 2~3 会变碎。
- `seg_gap`：断口，现为 1~2。改成 0 会让相邻同色段连成长条。
- `lit_share`：亮段比例，现为 0.62。调到 0.75 水面更亮更安静；调到 0.5 明暗各半，会更花。
- `thick`：两行高短段的比例，现为 0.28。调到 0.5 更接近参考图的块感。
- `drift`：漂移概率，现为 0.35。调到 0 变成直尺线，调到 0.6 会开始有台阶感。
- `PALETTE`：只改一项会破坏三色的明度梯度，校验里的配比断言会先报出来。

想换一套波纹排布，改 `build()` 里的种子偏移；几何、色板和所有断言都不变。

## 接入

- 水面是纯地砖，按 32 像素格平铺即可，四周接草地或岸线由过渡砖负责（草土过渡砖已有一整套，水岸过渡砖还没做）。
- 4 个变体随机取用；只用变体 0 也不会露接缝，但大面积会出现重复图案，`water-field-3x.png` 里能看出差别。
- 变体间不保证图案连续：跨砖的短段在拼缝处会断开一像素。三色低对比下看不出来，若以后加密到参考图的密度，建议只用单一变体或按行列固定变体。
- 河面之上的倒影、行船尾迹、涟漪动画都不在这张砖的范围里；动画可以利用“波线整体横向平移 1 像素”做循环，三色不需要改。

# 柳湾 · 光影田畦实现标准

入口：[柳湾光影田畦](../../prototype/pixel-farm/index.html)。开发者已确认采用 Canvas 2D 与二维像素素材，固定视角，不引入 Three.js。已清理平面/高差模式和厚度比较控件，当前入口只呈现已选方案。

## 已确认规则

- 河畔青绿配色；基础地格 32×32，普通作物种植单元 64×64、株行距 64，白菜 48×72。
- 左上受光，右下硬像素投影，根部/脚底接触阴影。投影按 Alpha 轮廓预生成，无模糊、无抗锯齿；暂未随太阳方向旋转。
- 田畦固定厚度 4 源像素，顶面与根部同步上移；只在连片田地外缘画土壁，不给干湿交界或每个基础格单独画盒子。
- 人物、建筑与作物按逻辑脚点纵坐标排序。人物进入田里时，遮挡它的前景叶片以 68% 不透明度显示。
- 二维镜头支持平移观察和整数倍率；后续按相同标准接入角色跟随。没有自由旋转或高差寻路。
- 小屋为 128×104 原生像素占位，基部 `(64,94)`；人物为 40×80，脚底 `(20,76)`；白菜原素材锚点 `(24,66)`。

当前场景 448×384 源像素，十二株白菜。田间根部位于单元内 `(32,54)`。人物站位、隐藏作物和干湿切换为观察工具，不代表已经实现移动、种植、生长或存档。

## 文件与重新生成

```sh
python prototype/pixel-farm/depth-generate.py
```

- [depth-generate.py](../../prototype/pixel-farm/depth-generate.py)：小屋与白菜/人物/小屋的像素投影。
- [ground-painter.js](../../prototype/pixel-farm/ground-painter.js)：地表和田畦顶面。
- [scene.js](../../prototype/pixel-farm/scene.js)：薄土壁、接触阴影、脚点排序、前景透显和观察控件。
- [depth-manifest.json](../../prototype/pixel-farm/depth-manifest.json)：素材、投影的尺寸和锚点，普通脚本版本同源生成。

原三版比较已完成选择。额外河岸侧壁、石地基和台阶不属于本次选定标准，相关比较实现已清理。完整季节、天气与时段光照仍按[场景配色方案](季节天气与场景配色方案.md)分批推进。

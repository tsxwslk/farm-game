# 季节、天气与场景配色方案

状态：开发者已确认「河畔青绿」作为柳湾的地面配色方向；以下季节、天气和时段变化为设计提案，尚未实现或验收。不改变现有季节、生长、湿度、温度和霜品质规则。

## 三层组合

环境素材的季节色板 + 当时的天气与时段光照 + 局部雨、雾、霜与灯光表现。人物、作物、建筑会受到克制的环境光影响，背包物品、文字和界面保持正常识别色。

正式版地表和种植单元均为 32×32 源像素。配色与效果沿用现有像素密度、通行和种植占地。

## 柳湾四季环境

| 季节 | 地面与树木 | 土路、水面与氛围 |
| --- | --- | --- |
| 春 | 河畔青绿为基准，嫩绿草地、浅新叶；少量新芽或花点 | 浅暖土路、清青水面，柔和日光 |
| 夏 | 草与树叶偏饱满深绿，局部明暗分层；水岸更浓绿 | 阳光略暖、水色更饱满，阴影略深，保留与湿土的明度差 |
| 秋 | 草地转橄榄绿与低饱和草黄；按树种做黄、赭、棕叶，保留常绿植物 | 土路略暖、水面偏灰青，少量落叶，不用满地碎点覆盖作物 |
| 冬 | 降饱和的灰绿、枯草米色与树种对应的落叶/常绿形态 | 清冷灰青光、低饱和土路与水面；霜或积雪由对应环境状态控制，不因进入冬季自动全图变白 |

以上是柳湾的区域方案，后续区域按自身气候另设色板。作物是否枯死、停长或休眠由现有物种与温度规则决定，环境换季不直接把所有作物变黄。树叶的落尽、积雪厚度等形态变化需要独立状态和少量素材，纯调色不能代替。

## 八种天气

| 天气 | 场景颜色 | 局部表现 |
| --- | --- | --- |
| 晴 | 保留当季基色，日间光偏中性暖 | 清楚但克制的阴影与水面反光 |
| 阴 | 稍微降亮度、降低暖色，阴影减弱 | 云影可选，植物和干湿土仍须可辨 |
| 雨 | 略冷、略暗，真实受雨地表按湿度变深 | 像素雨线、水纹与少量溅点，湿土不是全屏着色效果 |
| 雾 | 偏冷浅灰，远处装饰降低对比 | 近处农田和交互目标保持清楚，用像素层次表现雾；不新增视野或交互距离惩罚 |
| 风 | 沿用当前季节与光照，不额外强制改变色相 | 叶片/草丛轻摆、少量同方向落叶，不改变田间产量和品质 |
| 雷 | 天空光偏冷暗，保留可操作亮度 | 克制的局部雷光与雨；减少动态效果时关闭突变闪光 |
| 霜 | 晨光偏冷，地表边缘有浅白/淡青霜点 | 霜层与植物状态分别绘制；霜不直接表示作物已死亡 |
| 霾 | 低饱和灰绿、淡赭灰，与冷白雾区别 | 地方蠹蚀痕迹与余绪按已有状态更易辨认，界面文字保持对比 |

雨天由土壤规则更新每格湿度，渲染读取结果。阴、雾等天气的生长系数由模拟处理。

## 一天内的光照

清晨轻微淡金或青灰，正午采用最清晰的基准颜色，傍晚加暖光和少量偏冷阴影，夜间使用克制的蓝灰环境光，房屋灯与交互点提供局部暖色。夜间始终能辨认作物轮廓、湿土与选中单元。时段只调整画面，跨午夜仍按现有日结冻结规则处理。

首轮先做清晨、白天、傍晚、夜间固定预设用于对照，确定后再加入随游戏时间平滑过渡。减少动态效果时去掉快速云影、雷光和持续粒子干扰，保留静态天气辨识。

## 实现边界与验收

- 程序地面从「草、裸土、路、干土、湿土」的语义色生成四季版本，避免不同素材各自随意改色。
- 作物、人物和建筑保留各自基础图，按材质施加有限的环境光调整。红果、橙根、浅叶柄与衣服仍应认得出来。
- 天气与时段的场景光照处理发生在界面之前；图标、文字、物志插画不套用场景的雾霾和夜色。大气层与阴影继续按像素网格绘制，保持锐利边缘。
- 先制作同一布局的春夏秋冬晴天正午，再用春季基准查看八种天气，最后抽查夏季雨夜、秋季霾、冬季阴天/霜等组合。每次保留空地、满种、干湿相邻、人物与白色/红色/橙色识别物作参照。
- 所有组合都要能辨认作物、干湿土、道路与可操作目标；正式季节、天气数据尚未接入时，预览切换须标明为视觉预设。

优先验收四季底色和晴/阴/雨/夜间对照；完整八种天气的粒子、形态变化及后续区域气候版本分批扩充。既有游戏规则见[时钟季节与天气](../策划/时钟季节与天气.md)。

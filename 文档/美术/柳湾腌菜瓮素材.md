# 柳湾腌菜瓮

柳湾农舍院子里的腌菜瓮，48×48 透明底像素精灵，单件居中、圈足接地。**固定俯视微倾、左上受光**：宽口外翻、短颈、鼓腹、收底，口沿最上一行是朝天的顶面，暗红封布盖住口心、细麻绳勒在布下摆之下。全部由 Python + Pillow 逐像素绘制，无抗锯齿、无半透明边缘。

关键在**口要宽**。腌菜的缸是宽口的，口径接近肩宽（26 对 28）；做成窄口坛子就变成另一个物件了。它与并排的方形收获箱靠轮廓分开：这边是竖长的曲线，那边是扁平的方块。

## 结构

坐标从上往下排。整件 28×39，四周留白：上 6、下 3、左右各 10。

| 行 | 宽度 | 部位 |
| --- | --- | --- |
| 6~9 | 26 | 口沿外圈。第 7 行是朝天的顶面（釉色），6、8、9 行是唇的外壁 |
| 10 | 24 | 唇的外壁往下收一档 |
| 11 | 22 | 唇的前缘，与颈的受光面同色 |
| 12 | 20 | 封布下摆，比前缘各窄 1 像素，两侧露出陶颈 |
| 13 | 20 | 麻绳，比布下摆窄 2 像素 |
| 14~15 | 22 / 22 | 短颈，被唇与布压出一档暗 |
| 16~26 | 24 → 28 | 肩（最宽在 18~26 行，28 像素） |
| 27~43 | 26 → 18 | 腹，直腹缓收 |
| 44 | 16 | 圈足，比上一行再收 2 像素 |

**剖面。** 陶瓮是旋转体，正面轮廓就是一条连续曲线，所以这里用**逐行半宽剖面**而不是多边形顶点：每行 ±1 像素的步进本身就是这条曲线的像素表达。宽度恒为偶数（左右对称），bbox 中心恒落在 23.5。

口径 26 对肩宽 28，差 2 像素——这就是「宽口」的量化。颈收到 20，比口径窄 6，够读出「短颈」但不会断成两截。底 16，是最宽的 57%。

**口沿。** 顶上四行等宽 26，再往下两行收成 24、22，于是口的外轮廓自己就是一道弧。这里**不能用"椭圆顶面 + 椭圆外的陶壁"**：口只有五、六行高，椭圆在顶行只剩半个宽，露出来的陶壁在左右各墩两块，八倍下就是帽子上的两只耳朵。改成"整圈同宽、顶面取一行釉"之后，轮廓的台阶就只剩弧了。

**唇的明暗。** 只有第 7 行是朝天的面，取釉色；第 6、8、9 行是竖直的外壁，降一档到陶身受光色；第 11 行的前缘同理。整圈都刷釉色时，前缘会从暗红布与暗颈之间跳出来，在两端变成两只亮橙的角。

**封布。** 布面 20 宽、3 行（y=8~10），比口沿轮廓内缩 2 像素，四周各留 1~2 像素唇。下摆一行张在颈上（两侧各让 3 像素，露出陶颈）。布是软的：上缘受光、右侧压深、下摆一整行压到最暗——被绳勒住的地方不该反光。

**麻绳。** 一行，比布下摆窄 2 像素，中间六像素在下一行压暗一档。只画一条亮横线，绳就成了腰带；有下垂段、有暗侧，才读成勒紧的一圈。

**釉面。** 贴着左轮廓的纺锤形：宽度 = 3 + 4.5 × sin，覆盖 y=17~27，两端收、中段最宽（7 像素）。这一片是圆柱左缘的受光，形状跟着轮廓放收，所以不会像贴上去的一块补丁。

**明暗。** 横向位置按**最宽半径**归一化，不按当前行的半宽——按行归一化时，收腹会让同一条明暗分界线跟着轮廓往里拐，左肩的受光面被挤成一个三角形。分界线必须竖直，这是圆柱的性质。纵向的暗只加在两处：颈被压的一档，和 y≥38 之后圈足收进去的一段。

**轮廓。** 所有与透明相邻的像素取 `#40200E`，不描黑边。

## 踩过的坑

**做成窄口坛子。** 第一版口径只有 14 像素、肩 28，整只像泡酒的小口坛，不是腌菜缸。口径必须接近肩宽。

**口沿整行取亮，读成橙色横条。** 把最上一整行都刷成釉色，口就成了一条扁横条，左右两端还是橙的，像口沿被切成三段。后面试过的几种分档见下一条，最后定的是「顶面一行釉、唇壁降一档」。

**椭圆顶面 + 椭圆外的陶壁，读成两只耳朵。** 口只有五、六行高，横长椭圆在顶行只剩半个宽，露出来的陶壁在左右各墩一块，八倍下是帽子上的两只耳朵。试过缩小椭圆、放大椭圆、把口拔高到七行、把椭圆外改成釉色——都塌回"横带"或"耳朵"。正解是放弃椭圆：让口的外轮廓自己走弧，顶面只取一行釉。

**相邻两行轮廓差一格，可见底色就差两格。** 描深会吃掉每行最外一列，所以 y 行宽 24、y+1 行宽 26 时，可见的釉色差 2 像素，八倍下是一道台阶状的"耳"。口部最上面四行必须同宽。

**整圈刷釉色，前缘从暗布与暗颈之间跳出来。** 唇只有第 7 行是朝天的面，8~11 行是竖直的外壁与前缘，该降一档到陶身受光色。整圈同档时，前缘和颈的受光面断开，左右各成一只亮橙的角。

**布下摆铺满整行，读成方盒子。** 窄口时布 14 宽、6 行高，比例接近正方，怎么看都是一个盖儿。口放宽到 22 以后同样的画法变成「宽 22、高 2」的扁条，再让两侧各退 3 像素，才读成布裹在颈上。

**布 + 绳各占两行，堆成一条厚横带。** 口沿因此像浮在缸身之上、中间缺一段。布只留一行下摆、绳一行、颈两行，中间用 20 的窄腰过渡，才连成一体。

**明暗分界线跟着轮廓拐，左肩受光被挤成三角。** 逐行按半宽归一化，收腹时同一条界线会往里收，受光面变成一个上宽下窄的漏斗。改成按最宽半径归一化，界线是竖直的。

**纵向权重进主公式，成了斜切。** 用一条线性梯度（横向 + 纵向）算明暗，分界线是一条斜线，整只瓮像被斜着削掉一块。纵向只保留颈部与圈足两段。

**釉面画成多边形，是块碎边补丁。** 八个顶点的多边形在八倍下是一块边缘参差的色斑。改成沿左轮廓放收的纺锤形，读起来才是曲面上的反光。

**麻绳比釉面还亮。** `#C2995B` 的亮度 158，和釉面同档，在暗红布与暗褐颈之间成了一条抢眼的亮线。压到 `#AE8850`（141）。

**并排预览排错。** `field()` 先按 1 倍拼好画布、再整体放大；第一版是先建放大后的画布、又把坐标乘了一遍缩放，木箱落到格子外，右边还多出一块空草地。

## 校验

`python3 prototype/pixel-farm/jar-generate.py --verify` 需 exit 0。断言覆盖：

- 画布 48×48，alpha 只有 0 与 255，色板锁定（用到的都在板内，且没有闲置色）；
- 瓮身宽 26~30（当前 28）、整件高 ≥36（当前 39，比木箱高出 9）；
- 锚点 `(24, 44)`；
- **接地一整段**：y=44 上连续 16 像素（16~31），段数 = 1；
- 轮廓足够曲：最宽与最窄相差 ≥12（当前 28 对 16）；
- 最宽行落在肩部 18~30（当前 18~26）；
- 底宽 ≤ 最宽的 0.62（当前 16 / 28 = 0.57）；
- 明暗阶梯：釉−受光 ≥15、受光−主色 ≥15、主色−暗面 ≥15、暗面−轮廓 ≥15；
- 左侧陶身均值 − 右侧 ≥12（当前 110 − 86）；
- 釉面重心在左上（x < 22、y < 30，当前 14.1 / 22.0），占面积 5%~32%（当前 8%）；
- 封布 ≥40 像素（当前 78），重心在瓮口（y < 13，当前 9.5），红色分量 R−max(G,B) ≥30（当前 93）；
- 麻绳 ≥12 像素（当前 22）。

校验只卡形状与光的关系，卡不了"读起来像不像"。口沿那几版的问题（横条、方盒、两只耳朵）全部通过了断言，只能靠 `jar-8x.png` 和口部的 16 倍裁切看出来。

## 接入

锚点 `(24, 44)`，接地行 44，整件 28×39，约合 0.9×1.2 个 32 像素地格。地面投影由游戏绘制，素材里不烘焙。

圈足是完整的 16 像素一段，可以直接压在草地或裸土上。与收获箱同场时它更高更窄，见 `jar-field-4x.png`；在深色耕地上暗面会接近地面色，靠轮廓那一圈分离，属于正常明暗关系。

# 柳湾正式版首日设计

2026-11-24。首日从荒地开垦开始，沿用春季、樱桃萝卜和盐渍樱桃萝卜这条使用线。玩家先清理落脚处，亲手做出设施，再把第一种作物用回生活。可打开现有 Demo 对照操作与比例，正式版按本文调整开局、界面和设施来源。[柳湾可玩 Demo](../../prototype/pixel-farm/index.html) · [项目指南](../../项目指南.md)

## 1. 荒地开局与首日动线

开局地表保留草地、裸土和河流。田记所旁有货箱，北侧林缘以橡树为主，柳树主要沿河分布，林缘东头有一处旧制盐台。田块由玩家清理后开垦，田记所门口和取水路线保持可走。盐灶和腌菜缸由玩家制作。[世界设定](世界设定.md#4-地理结构) · [项目指南](../../项目指南.md#已确认的地图方案)

**通用建材是木材和石材。** 用斧子砍树取得木材，用石镐开采普通石头取得石材。烧腌菜缸另需黏土，可在河边的裸土岸用锄头挖取。岩盐沿用作第一条使用线的原料。首轮建议把它藏在一块可开采的岩石里，敲开后才发现。樱桃萝卜种子建议放进现有货箱，让玩家有明确入口。[首条使用线](物种与收集.md#柳湾开局与首条使用线)

首日试玩顺序建议如下。

1. 打开田记所门旁的货箱，从仓库把种子移到背包。查看物志，认清开局工具与第一条用途。
2. 砍树、采石，腾出第一块能走到的地。收齐至少一座设施的材料，并留树石供后续开垦。
3. 翻地、播种、到河边取水、回田浇水。取水时也可挖黏土。等待生长时做盐灶、烧腌菜缸、找岩盐或再清一块地。
4. 用盐灶把岩盐制成一批粗盐，收获后留一份樱桃萝卜腌制。余盐可继续腌菜或炖鲫鱼汤。多余萝卜可留种，萝卜、腌萝卜、鲫鱼和鱼汤都可卖给田记所。首次上锚、稿酬和归档可在物志里查看。

首日要能完成开垦、播种，并在生长期间继续采集或营建。第一次收获及上锚落在哪一天，等正常流速试玩后决定。起步资源需验证够做两座设施，普通木材、石材和黏土应有后续可取得的来源。资源数量、补充方式和摆放坐标待定。[制作、摆放与搬移](#5-制作摆放与搬移) · [首日买卖](#6-首日买卖)

## 2. 物志图册

地图上的用途文案、缺字、恢复后的文字都移入物志。压在地图上的提示限于临时操作反馈。物志可沿用 `J` 打开，做成游戏内翻阅的图册。建议用纸张色的跨页、手绘或像素插图、页签和克制的旧墨色。左页是分册与条目，右页显示插图、发现线索、用途、剩余活动时间及归档结果。窄屏切成单页，沿用同一组信息。

| 条目状态 | 页面呈现 |
| --- | --- |
| 未发现 | 留白或淡轮廓，保留可读的获取线索和条件。 |
| 已发现 | 显示名称、图像及可尝试的用法。有时限时显示剩余活动时间。 |
| 已上锚 | 显示完整图文、已验证用法和稿酬记录。字迹恢复在该页呈现。 |

生成首瓮盐渍樱桃萝卜时，仍按实际投入的樱桃萝卜与岩盐批次分别判定是否上锚，并给符合条件的条目结一次稿酬。田记所可继续负责首卷的提交与归档；归档结果记在物志里。[点亮与永久保留](物种与收集.md#42-点亮与永久保留) · [首次上锚倒计时](物种与收集.md#43-首次上锚倒计时)

## 3. 快捷栏与多次作业

正式版默认交互键为 `F`。靠近目标后，按 `F` 执行提示中的动作，包括使用当前工具、开货箱和操作设施。画面上的操作提示统一标注 `F`。

开局工具为锄头、石镐、水壶、钓竿和斧子。没有选中物品时即为空手。取水、浇水、翻地、恢复草地、砍树和采挖需要对应工具，播种需要选中种子。收获和打开田记所、仓库、盐灶、腌菜缸随时可操作。

底部快捷栏对应背包当前一排。点格子、按 `1–8` 或滚轮选用物品，`Tab` 或点击排号换排。点击空格、再次选中当前格或按 `Esc` 取消选用。`B` 打开背包，田记所门旁的货箱打开仓库与背包。拖拽物品可以移动、交换或合堆。使用鼠标时悬浮查看物品卡，触屏时点按查看。领用、制作和交易从背包取物。指向目标时显示将执行的动作，例如「石镐 · 采石」或「水壶 · 浇水」。点目标可以寻路到操作位置，到达后才开始计算有效操作。

| 工具 | 作用 | 首轮试值 |
| --- | --- | --- |
| 锄头 | 开垦可达的空闲草地，在裸土岸挖黏土 | 每个 32×32 草地格可开垦成一穴。翻地和挖黏土各需 3 次有效操作。 |
| 石镐 | 采石材和岩盐，把空耕地恢复成草地 | 普通石头 3 次，含盐岩石 4 次，空耕地 1 次。地里还有作物时，收获后可恢复。 |
| 斧子 | 砍伐柳湾的柳树和橡树取得木材、清出占地 | 每棵树 4 次有效砍击，产出木材 ×4。 |
| 水壶 | 在可达河岸取水，在菜畦浇水 | 一次有效操作给予即时反馈。容量待试玩。 |
| 钓竿 | 沿可达河岸抛竿。水面有涟漪的地方咬钩更快、概率更高。 | 涟漪约每 90 游戏分钟换一批。咬钩后看标记，在绿区内成功收线 3 次即可入包。 |
| 樱桃萝卜种子 | 在空菜畦播种 | 每次成功播种扣一粒。 |

每次有效命中后在目标附近显示进度条和次数，如 `2/4`。接近已做了一半的目标时能重新看到进度。首轮建议离开或切工具时保留已完成次数，读档也还原；中途取消的那一击只有命中后才计数。最后一击同时提交地块变化或资源产出。连续点按、越过午夜、重载页面都不能多扣或多发。进度跟实际模拟事件走，动画只负责呈现。[场景动作与存档](../开发/时钟与存档架构.md#61-场景建筑与操作)

## 4. M 键地图

移除地点按钮及自动走到指定地点的功能。按 `M` 开关地图，触屏可用地图图标。图上标出玩家位置、田记所、河流和已知地点，玩家建好的设施随摆放位置更新。地图用于查看位置和方向，点击标注可读名称。回到现场后照常用 WASD 或点击地面移动。

开局地图建议标出河流与田记所，含盐岩石的位置在发现后再记入。地图标注范围与后续区域出口的揭示时机，随首日路线一起试玩确认。

### 场景滚轮缩放

试玩反馈是滚轮轻滚时容易一下到最大或最小倍率，中间档位很难停住。正式版建议保留可停留的中间档，缩小相邻档位的倍率差。将鼠标和触控板的滚动输入按阈值累计，达到阈值才切一档，并限制同一串密集输入的换档频率。`M` 键单独开关地图，`Shift` + 滚轮或加减按钮调镜头倍率。

验收时用带刻度的鼠标滚轮和触控板分别试。轻滚一次只切到相邻档，停手后能留在中间倍率，持续滚动能逐步到达上下限。倍率间距、输入阈值和换档间隔随试玩调整。

### 窄屏操作

手机上建议横屏耕作、采集和摆放设施。横屏能同时看到角色、目标及周围空地，也有空间把移动和交互分到左右两侧。横屏的高度较紧，工具按钮和时间条用紧凑布局，背包、物志和地图按需展开。是否横屏由玩家决定。

- **横屏。** 点击地面寻路、点击目标操作。左下可展开方向键，底部快捷栏选工具，右侧放与 `F` 等效的交互按钮。触碰按钮只执行对应动作，地图点击才会寻路或选中目标。
- **竖屏。** 仍可点击寻路、选工具、操作和摆放。底部收拢次要按钮，地图、物志和买卖用可滚动的单页面板，存档入口在两种方向下都可达。
- **实现与验收。** 触屏和键鼠共用移动、选中及操作入口。按可用宽高布局，旋转时重算画布、镜头和点按坐标，保留当前工具与游戏状态。触屏提供放大和缩小按钮。分别用窄屏竖向和低高度横向完成选工具、翻地、开货箱和摆放，检查按钮是否挡住目标及系统手势区。[场景与交互架构](../开发/时钟与存档架构.md#61-场景建筑与操作)

## 5. 制作、摆放与搬移

盐灶和腌菜缸从零制作，开局不赠送成品。用木材和石材建盐灶。首轮方案是在盐灶内设带盖烧制模式，消耗黏土与木材制作腌菜缸，再选空地摆放。背包制作页显示配方与缺料提示，物志给出黏土和用途线索。

- **制作与放置。** 建盐灶时，材料充足即可进入放置预览，确认位置时一次扣料。腌菜缸在开烧时扣料，完工入包，摆放时消耗成品缸。水面、田记所门口、已有设施、树石和已耕作的田块挡住摆放，交互入口也必须可达。取消预览保留原材料或成品缸。
- **后续搬移。** 建议选中设施后长按抬起，同时提供「搬移」作为键盘或触屏入口。预览时设施仍占原位。确认新位置后更新通行和交互点，取消回原位。搬移沿用原设施和已保存的数据，无需重做或再扣料。
- **加工中的处理。** 首轮建议等加工完再搬，并提示剩余时间，先避免原料和半成品被中断。设施位置、配方进度及库存随档保存。搬移成功后，地图标注也跟随。

### 河岸黏土与烧缸


黏土来自**裸土河岸中较细、偏灰褐的土层**。首版在可步行岸边配置固定的浅层黏土点，用地表色差表现，玩家靠近后用锄头操作。取水目标仍在同一段河岸，挖黏土的目标归属于岸上土层。该地块保留原地表与通行用途。首轮建议第一处保证产出一整只缸的用量，耗尽后显示状态，并在后续日刷新可继续采的点位。离线期间依照现有时钟规则保持状态。[建材来源](土壤与经济.md#82-建材必须分散来源)

| 步骤 | 首轮试值和行为 |
| --- | --- |
| 做盐灶 | 石材 ×4、木材 ×2。手里有材料即可选址，确认摆放后扣料。 |
| 挖黏土 | 到可达河岸，用锄头有效挖 3 次，出黏土 ×3。开局保证至少一处够做首缸。 |
| 塑坯烧制 | 盐灶增加一个带盖的烧制模式。投黏土 ×3、木材 ×1，在菜单内合并塑坯和点火操作，试玩可用 90 游戏分钟。盐灶同一时间执行一项工作，制盐与烧制共用队列和活动时钟。 |
| 领取并摆放 | 烧完得到一只腌菜缸放进背包。背包空间不足时，成品留在盐灶等待领取。选择合适空地后消耗一只缸生成设施，后续搬移沿用原设施。 |

让「取水时顺手挖土」成为第一段自然动线。等待萝卜生长时烧缸，等缸能摆下来了再安排首批岩盐和粗盐。试玩要验证先采盐的玩家也有足够时间完成制盐和腌制。如果烧缸占用过久，优先调烧制时长或岩盐倒计时的试值。[加工与跨日规则](../开发/时钟与存档架构.md#2-时钟模型)

### 制盐与料理配方

| 配方 | 设施 | 投入 | 产出 | 活动分钟 |
| --- | --- | --- | --- | --- |
| 制粗盐 | 盐灶 | 岩盐 ×1 | 粗盐 ×12 | 45 |
| 腌樱桃萝卜 | 腌菜缸 | 樱桃萝卜 ×1、粗盐 ×3 | 盐渍樱桃萝卜 ×1 | 75 |
| 炖鲫鱼汤 | 盐灶 | 鲫鱼 ×1、粗盐 ×1 | 鲫鱼汤 ×1 | 45 |

粗盐按一份调味用量计。一次制盐可供四份腌菜或十二碗鱼汤，也可混用。粗盐各份继承投入岩盐的批次时限。腌萝卜完工时，分别检查实际投入的萝卜和粗盐。炖汤的上锚对象是鲫鱼，烹调优先消耗已超时或无上锚时限的粗盐。

## 6. 首日买卖

沿用「文」为单一货币。从 0 文也能开垦并做出第一套设施。[货币规则](土壤与经济.md#5-货币)

### 钱从哪里来

**让田记所收购余货。** 靠近田记所后打开买卖账面，沿用田记所留存的记账与付款机关。页面显示单价、背包可卖数量和合计，确认后即刻扣货到账，日结只汇总已经入账的交易。首轮用固定收购价，开放樱桃萝卜、盐渍樱桃萝卜、鲫鱼和鲫鱼汤。木材、石材可在后续加进指定用品的收购委托，优先让首日采到的建材用于开垦和营建。[田记所设定](世界设定.md#3-名词表)

| 进账来源 | 首版处理 |
| --- | --- |
| 出售原料和加工品 | 萝卜、腌萝卜、鲫鱼和鲫鱼汤都按出售数量收钱。超时批次的实物仍可正常出售。 |
| 首次上锚稿酬 | 沿用实际原料批次和时限判定。符合条件的条目各付一次，物志和钱袋同步更新。普通出售按交易计价，重复提交首卷只显示已有记录。 |
| 日常委托 | 下一轮再加。田记所发布按数量收取的委托，履约付钱。普通委托按经济规则结算，只有写明最终用途并符合上锚条件的委托才影响物志。 |

本次出售将用掉背包里最后一份仍在上锚期限内的萝卜或鲫鱼时，界面提示「这份还可用于首条用途」，玩家仍可确认出售。交易页显示真实可售的背包库存，有在制品占用的材料已从背包扣除。[首次上锚与实际投入批次](物种与收集.md#43-首次上锚倒计时)

### 钱花在哪里

**第一笔花费用于补种。** 田记所账面加「买入」页，首轮供应少量樱桃萝卜种子。种植仍可走留种路线。首日货箱给初始种子，首轮另保留一个不花钱的补种条件，例如在无种子、无在长作物且背包也没有可留种萝卜时，从田记所领一粒补种种子。玩家卖掉最后一份收成或者错过上锚后，仍有重新尝试的路径。[种子来源与留种](土壤与经济.md#6-种子来源六渠道)

| 支出 | 启用时机与效果 |
| --- | --- |
| 常规种子 | 首版启用，花文补充播种量。 |
| 背包、仓库扩容 | 可在各自面板花文购买。背包每次加 8 格，最多 32 格。仓库每次加 24 格，暂不设上限。 |
| 买地契、工具升级、建筑升级 | 有稳定余货收入后接入。地契扩地，工具升级可减少部分操作次数，建筑升级提升产能。保留相应的材料要求。 |

首轮试值为萝卜 **12 文/份**、盐渍萝卜 **30 文/份**、鲫鱼 **16 文/条**、鲫鱼汤 **26 文/碗**、萝卜种子 **6 文/粒**。将鲫鱼炖成汤可多卖 10 文，需耗一份粗盐并占用盐灶 45 活动分钟。用正常流速记录钓鱼耗时、盐灶排队和加工收入后再校准价格。盐灶和首只腌菜缸的制作可以在 **0 文** 时完成。[资金出口与数值口径](土壤与经济.md#10-资金出口)

## 7. 动态表现

动态先服务操作可读性，再给荒地加轻微环境变化。沿用 Canvas 2D 和像素脚点排序，固定渲染尺度，角色工具用短帧序列叠在握点上。环境循环放在独立绘制层，只更新视野内需要变化的对象；已拼好的地面仍可缓存。

| 优先级 | 表现 | 实现建议 |
| --- | --- | --- |
| 先接 | 走路和工具命中 | 四向走路短循环。挥锄、敲石、砍树各有预备、命中、收势。命中帧配土粒、石屑或木屑和一次进度跳动。最后一击后显示翻开的土或卸下的障碍。 |
| 先接 | 水与种植 | 取水、浇水各有短动作，浇后切到湿土。作物到生长阈值时切换原阶段图。河面复用水砖，可用 2–3 帧低对比短水纹缓慢轮换。 |
| 随后接 | 设施 | 盐灶工作时冒少量热气，完工用短提示。静置腌菜缸保持安静，用加工状态提示进度。 |
| 随后接 | 物志反馈 | 首次上锚时在图册页内完成一次短显墨，让玩家能读到刚找回的用法。午夜弹窗、失焦和暂停都停住操作动画，读档按已保存进度恢复。 |

## 8. 接入与试玩验收

正式版首轮采用浏览器本地存档与 JSON 导出、导入。换设备前导出，可用常用网盘传递文件，在另一台设备导入后继续。跨设备读档要验田块、在制品、物志、钱袋和当晚的日结页。[跨设备续玩](../开发/时钟与存档架构.md#44-跨设备续玩)

1. **先通买卖。** 沿用物品稳定标识和现有钱袋，以内容表配收购价、售价与当日库存。一次交易内复验数量、余额与可用容量，再提交库存和账目。交易、稿酬与后续委托分别记来源，读档、连点确认或日结都只入账一次。
2. **再通河岸与烧制。** 黏土点沿用可重复命中的操作进度，最后一击一次结算。加工队列记录投入、预计完工的活动分钟和待领取成品。确认摆放才消耗背包里的缸。午夜、失焦和读档沿用既有加工规则。
3. **用新档从头试玩。** 从 0 文建好盐灶并烧出腌菜缸，卖一份额外收成并用货款补种，再完成腌菜上锚。重点检查卖完最后一份以后能恢复播种、烧制跨午夜能续算、背包满时仍可领回成品，以及移动腌菜缸后还能使用。

首轮记录第一次出售和第一次花钱的时间、收支、缺料次数，以及烧缸是否挤占制盐。用这些记录调整配方、产量和价格，并校准扩容价格与地契的开放时机。

先看玩家第一次放下锄头后，能否辨认当前工具、操作次数和下一件能做的事。接下来验证在空地做出两座设施、搬移后仍可使用和读档，在腌制后从物志读到完整用法。记录第一次翻好地、浇水、制好设施、收获和上锚各花多久，再定正式配方数量、操作次数、资源密度和动画节奏。[正式游戏验收](../验收/测试与验收记录.md#正式游戏接入后验收)

# 时钟、季节与天气

**状态**：v0.1 框架
**范围**：时间模型、日边界、季节与年、生长档位、天气与预报
**不包含**：具体物种的生长天数（见物种表，待定）

---

## 1. 时间模型：激活计时

活动日按所选计时模式推进。默认要求窗口可见且有焦点。开启「窗口可见时继续计时」后，游戏可以在副屏失焦时继续走表。

| 条件 | 行为 |
| --- | --- |
| 活动日可见、有焦点、未暂停 | 推进 |
| 页面仍可见但失去焦点 | 默认暂停。开启副屏计时后继续推进作物、加工和上锚倒计时，移动和钓鱼输入等待焦点恢复 |
| 切走游戏标签页或最小化，浏览器报告页面隐藏 | 自动暂停 |
| 手动暂停（空格） | 暂停 |
| 午夜日结 | 等待玩家确认，可阅读、翻页、存档 |
| 关闭页面 | 时间静止，无离线结算 |

**状态指示**：顶部常驻一枚状态灯，显示活动时刻、暂停或「第 N 天 · 日结」。必须始终可见，避免玩家误判。

**存档**：随时可存，无冷却。存全量快照，不存增量。

**由此排除的设计**：无离线结算、无 catch-up 模拟、无回归弹窗。

## 2. 一天

| 项 | 值 |
| --- | --- |
| 一天时长 | **18 分钟前台激活时间（正常流速）** |
| 一天跨度 | 06:00–24:00 为活动时段，午夜打开当天结算，确认后进入次日 06:00 |
| 换算 | 1 游戏小时 = 1 现实分钟；**1 游戏分钟 = 1 现实秒** |

**时间纯自然流逝，动作不额外扣时间。** 不做"种一株扣 5 分钟"这类行动税，否则会退化成行动预算制，与随时暂停的松弛感冲突。

18:00–24:00 可安排夜钓和余绪探索。00:00–06:00 是日结的叙事时段：画面可从夜色翻到天将明，游戏时钟停在午夜。读几页、等多久、读档几次都不消耗活动分钟。首次上锚倒计时与加工队列共用活动时钟，午夜一起暂停，确认次日时沿用剩余时间。[倒计时规则](物种与收集.md#43-首次上锚倒计时)

## 3. 午夜日结与次日清晨

23:59 后再走 1 游戏分钟，先结清这段时间内的生长、加工与已完成动作，再打开「第 N 天」结算。玩家留在原地点，田间、在制品、天气暴露、冷却和互动动作全部冻结。日结账页展示当日收入、支出、稿酬、钱袋余额与有金额的明细。当天无收支时也保留日期、余额和确认按钮。

只有点击「进入第 N+1 天」才切换到 06:00。按新日历先更新季节，再依次刷新一次：

1. 天气推进（按预报表翻页，不做随机重掷）
2. 商店换货
3. 委托板刷新
4. 月相推进
5. 动物产出结算
6. 土壤湿度与肥力恢复一档
7. 刷新余绪显形条件

新日环境就绪后，在首个获准推进的活动时刻检查地块温度与暴露，再累计生长与加工。失焦恢复、读档与倍率步进都停在日结；重复点击同一晚的确认只换日一次。日结可手动存档，重开回到同一晚、同一页。

## 4. 季节与年

| 项 | 值 | 正常流速的活动时长（不含日结停留） |
| --- | --- | --- |
| 一季 | 28 天 | 8.4 小时 |
| 一年 | 112 天（4 季） | **33.6 小时** |

按正常流速，常规作物的 5–9 个足速生长日约需 90–162 分钟前台时间。季节规划遵循以下约定。

- **季节专属物种至少占 50%。** 分母是全游戏可收录的生物物种，按稳定物种 ID 去重（含作物、动物、虫、鱼及生物类采集物）；加工品、非生物材料、颜色与品质均不计。分子是常规野外来源与露天栽培合计只在一个季节产生新个体或主产物的物种，合计须满足「专属数 × 2 ≥ 物种总数」。
- 内容表填写各区的自然可得季，汇总所有区域、野外来源与露天收成的并集；物种能在别区或另一季自然取得，就不能计为单季专属。留存库存、留种、温室与人工交易不改变自然分布。作物按露天新产物的成熟季统计，上季已成熟、本季才摘取的果实仍归上季；能在多个季节新成熟的作物不计入分子。洞穴、河湖等野外来源均参与统计。
- 每季排一张活动表，既有当季可找的生物，也有与农事错开的采集、找余绪、钓鱼和挖矿窗口。第一幕保留全年可取得的基础工具材料和至少一条当季可做的入门使用线。

## 5. 生长档位

| 档 | 天数 | 特征 | 通常是否需要跨季生长 |
| --- | --- | --- | --- |
| 速生 | 1-3 | 叶菜、葱类、竹笋 | 否 |
| 常规 | 5-9 | 茄科、瓜类、豆类 | 否 |
| 长程 | 12-18 | 禾谷、块茎、鳞茎 | 否 |
| 跨季 | 32-40 | 越冬型谷物与纤维作物 | 是，跨 1 季 |
| 多年生 | 足速下首次成熟 ≤28 天，之后按季反复结果 | 果树、藤本、灌木浆果 | 植株跨季保留 |

**硬约束**：

1. **足速生长所需时长上限为 40 天**（每天 1,080 活动分钟；季节停滞或减速会延长实际等待），远小于一年。不存在"需要养一年才长大"的物种。
2. **多年生作物（果树、藤本、灌木浆果）移栽后首次进入结果期所需足速生长日 ≤28 天**，在满足生长条件时结果。禁止"先养两三年再结果"的设定。
3. **结构性保证**：每个区域必须覆盖四季各有可结果的多年生物种。这样无论玩家何时进入该区，当季都有多年生作物产出，不存在"要等一整年才看得到它结果"的情况。
4. 跨季档作物（32-40 天）因播种时间较晚，日历上可能落在跨年的位置，但**成因是播种时机，不是成长周期**，不构成"漫长"。给这类作物安排足够的可生长季，确保存在从播种到收成的可行窗口。
5. 竹为速生档，割后再生，不作为多年生处理。

**一句话口径**：不允许"成长周期长"的物种，只允许"播种窗口窄"的物种。

### 跨季规则

物种表分别填写四季的倍率（相对该物种足速）、可播种和可结果季、低温反应及恢复条件。「适季」与「耐季」是给玩家看的标签，各自可以有不同倍率；环境不适时，有的仍缓慢生长，有的停长或进入休眠。示例值用于校准首区：

| 物种 | 露天季节与速率示例 | 低温与恢复 |
| --- | --- | --- |
| 辣椒 | 夏适季 100%，暖秋耐季 60%，春 35%，冬停长 | 有效温度低于 0°C 即冻死，包括成熟待收株；等于 0°C 只停长。存活时温度回到 0°C 以上按当季倍率恢复 |
| 菠菜 | 春适季 100%，秋适季 90%，冬耐季 30%，夏 15% | 有效温度低于 0°C 时停长，保留阶段，回到 0°C 及以上按季恢复 |
| 葡萄 | 夏适季 100%，春耐季 75%，秋耐季 40%，冬休眠 | 休眠保留植株，春季满足返青条件后恢复；待采果实在植株存活时保留，采完显示休眠帧 |

先取地块环境：露天读区域当前温度和季节；温室读设施维持的有效温度与栽培季。依次判定致死、休眠或停长，存活且可生长时才累计「活动分钟 × 当季倍率 × 天气生长系数」。温室内隔绝露天霜及阴天修正。冻死是不可逆状态，未收产物随株损失，清株后可重种；成熟本身没有过熟倒计时。休眠与停长均保存已积累的进度。普通防霜覆盖只防品质损失；有保温能力的设施须明示其有效温度。

午夜不取样；确认次日后才读取新日环境。同一活动日内温度越过阈值也须判定，温度致死与每天最多一次的霜品质修正分别记录。

## 6. 天气

### 6.1 设计原则

**每种天气都必须是一个内容窗口，不能只是惩罚。** 玩家的时间不应被固定在种地一件事上——天气要成为调度钓鱼、采集、挖矿、加工的理由。

### 6.2 八种天气

| 天气 | 对环境的作用 | 独有产出类别（内容由物种表填） |
| --- | --- | --- |
| 晴 | 基准；蜂活性高 | 蜂产品增量、晒制与晒盐效率提升 |
| 阴 | 生长 -10%，蒸发减弱 | 阴生菌类 |
| 雨 | 免浇水，湿度回升 | 环节动物类鱼饵、雨后菌群、雨水收集 |
| 雾 | 蒸发归零，光照不足 | 雾生菌、稀有昆虫、鱼类稀有度上浮 |
| 风 | 推动风力设施，改变环境表现 | 风力加工、候鸟观察；田间作物的数量、品质、收获方式均保持原值 |
| 雷 | 有几率损坏露天设备（可预防） | 雷击木类建材、雷雨菌 |
| 霜 | 存活的在田作物按配置结算霜品质，覆盖可防品质霜损 | 喜霜作物可升质，霜敏作物可降质，中性保持原品质 |
| 霾 | 蠹蚀的环境痕迹更明显 | **余绪稳定显形** |

**两条必须保留的设计**：

1. **霜效在活动日内触发。** 霜日首次活动暴露时先判定存活，再对在田植株判定品质；当日新栽植株从首次暴露时判定。每株每游戏日最多一次，记录暴露日与修正值。成熟待收也可受霜；采收入包时锁定品质。修正夹在最低档与该株品质上限之间，覆盖或熏烟须在暴露前生效。时钟暂停期间不触发。
2. **霾天让余绪稳定显形。** 玩家可利用预报安排寻找余绪的行程。

雷造成的损坏必须可预防（避雷针、收纳设备），不得构成意外惩罚。

### 6.3 预报

**预报 100% 准确，不做概率。**

预报同时给出区域活动时段的最低气温与低温时段，播种预览标明作物致死阈值和温室有效温度。

| 层级 | 视野 | 获取方式 |
| --- | --- | --- |
| 基础 | 7 天 | 起始即拥有（田记所旧址的风向标） |
| 中级 | 14 天 | 建造气象台 |
| 高级 | 28 天（整季） | 建造观星台（后期） |

#### 柳湾春季试玩

点击右上角天气可查看田记所风向标的七日预报。试玩按「晴、雨、霾、晴、晴、雨、晴」循环，错过第 3 天可等第 10 天。确认进入次日后才换天气。

雨天的菜畦显示湿土。换到雨天时，仍干着的已播种子从 06:00 开始生长。雨中刚播的种子从播种时开始生长，不消耗水壶储水。已开始生长的作物沿用原起点，雨停后照常生长。霾天全活动日可到旧制盐台西侧采集芥菜余绪。本轮预报显示天气，低温时段与季节变化留待后续接入。[复原流程](物种与收集.md#5-区域余绪与首次发现)

### 6.4 与地脉的关系

- 风向可改变地脉流向的表现；作物收获的数量、品质和掉落表不读取风向或风天临时变化。
- 雷雨会短期激活地脉，提升当日变异率
- 月相影响地脉涨落，进而影响鱼类出现与变异
- 地脉与天气的耦合只做正向加成，不做惩罚叠加

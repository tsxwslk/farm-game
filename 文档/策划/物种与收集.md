# 物种模型与物志收集

**状态**：v0.1 框架
**范围**：物种实体定义、收益结构、生长阶段、物志条目状态机、稀有度模型
**不包含**：具体物种清单（待图标方案稳定后另立物种表）

---

## 1. 种植作物按一株结算

**硬约束**：种植系统中的一株实例对应一株完整植物，不把它的不同部位拆成多个收获目标。

一株作物是"一个东西"。它地上部分和地下部分属于同一株，收获时一并结算，不是两个可以分别采集的对象。

由此推出的三条规则：

1. **不做「部位型条目」**。同一株作物的可食部分不产生独立收获动作。
2. **不做「先采叶、后挖根」的二段式收获**。收获是一次动作，一次结算。
3. **副产物在收获时同时获得**，不需要额外操作，也不占用额外时间。

**这条约束的理由**：物种表一旦允许拆部位，条目数会以部位数膨胀，而玩家的实际行为没有增加——只是多按几次按钮。收集的乐趣在于"见到新东西"，不在于"多一种获得方式"。

## 2. 收益结构

一次收获同时结算三类产出：

| 类型 | 说明 | 是否保证获得 |
| --- | --- | --- |
| 主产物 | 该物种的核心收获物，卖价与加工的主要原料 | 是 |
| 副产物 | 同株上的附带产出，随主产物一并获得 | 是，但数量受条件影响 |
| 概率产物 | 稀有掉落，受土壤匹配度、天气、地脉、月相影响 | 否，有概率表 |

**规则**：
- 作物副产物可以是库存材料；只有策划指定有独立收集意义的对象才有物志条目标识。
- 概率产物可以是独立物种（如某种菌、某种虫），也可以是材料
- 三类产出一次入包。库存按物品标识和品质堆叠。外观颜色只影响显示；同品质的两种颜色果实进入同一堆，可互换用于出售、留种、加工或交付。不同品质可以分堆，同享一条收集记录。

**数据结构骨架**（字段为约定，不含内容）：

```
species
├── id
├── name
├── family            # 科属，决定连作障碍与土壤偏好
├── lifecycle         # 生长档位：速生/常规/长程/跨季/多年生
├── growth            # 各阶段足速时长、逐季倍率、播种/成熟季、温度反应及恢复条件
├── seedSaving        # 可留种时填写主产物单位、每份粒数（整数 ≥2）
├── soil              # pH 偏好、养分消耗侧重
├── yield
│   ├── main          # 主产物：id、数量区间、品质上限
│   ├── byproduct[]   # 副产物：id、数量区间、触发条件
│   └── rare[]        # 概率产物：id、概率、加成来源
├── art               # 图标与阶段图引用（对齐美术规范）
├── entry             # 物志条目（见第 4 节）
└── tags              # 可上锚途径：料理 / 染色 / 饲料 / 建材 …
```

## 3. 生长阶段

阶段划分**直接沿用美术规范**，不另造一套：

| 阶段 | 用途 |
| --- | --- |
| 刚出土 | 可选帧，用于"已发芽"的即时反馈 |
| 幼苗 | 第一帧有辨识度的叶已展开 |
| 生长中期 | 至少出现一种可见结构变化（抽藤、分枝、分蘖、莲座扩张、拔高） |
| 田间成熟 | 可采收，果实连枝或根肩外露 |
| 背包收获物 | 重新取景，采收部位占画面主体 |

**跨阶段约束**：相邻帧必须保持主茎走向或基部位置，不允许跳变。多年生作物额外需要"休眠"帧（进入配置的休眠条件时显示）。停长保留原阶段，冻死使用枯株标识，采收入口随之关闭。

字段上，每个阶段对应一张图；`刚出土` 为可选，其余为必需。

## 4. 物志条目

### 4.1 条目结构

| 字段 | 说明 |
| --- | --- |
| 条目 id | 每个收集对象一个稳定标识。库存物品或养殖、捕获事件映射到该标识；色板不参与标识、进度、稿酬或上锚判定 |
| 分册 | 唯一主册，区域、获取方式和用途可多选 |
| 状态 | 未收录或已点亮，由首次有效用途决定；加工品按首次实际制成判定 |
| 首次收录时间 | 用于稿酬结算 |
| 已获品质档位 | 位掩码，记录收到过哪几档 |
| 首次上锚倒计时 | 未点亮的源条目保存本轮尝试的标识与截止活动分钟。时长按条目配置 |
| 已上锚途径 | 位掩码，记录通过哪些方式被使用过 |
| 揭示文本 | 寻找条件、已发现标记和可尝试的用途，分步揭示 |

### 4.2 点亮与永久保留

首次收获、采集、捕获、领养或复原，只记「已发现」和已获品质，允许查看用途线索。发现标记与收录状态分开保存，分册点亮数只统计已收录的唯一条目。

**使用线**从有来源的原料通向内容表指定的生活用途。苹果熬成果酱，以「果酱制成」为终点；若指定「矿石→金属锭→建成炉具」，则冶炼只保留来源，炉具落成才点亮该批矿石。出售、留种、持有、预订配方或普通交货都只改变库存。委托明确写出最终用途且已经履约，才算这条线完成。

完成时按实际耗用批次回溯到使用线指定的源条目；同一源只记一次。多原料配方只登记配方声明的来源角色，替代材料按实际选用者登记。动物产物沿用来源动物，半成品沿用实际原料来源；同物同品质可合堆显示，内部保留可分摊的来源数量。中途取消或仅经过同类成品，不能凭配方表倒推出未使用的物种。

**首条在限时内完成的有效使用线**同时登记途径、永久点亮源条目并发放该条目的首次稿酬。条目点亮后，后续新用途只补途径。加工品册记录制作成果，指定成品首次实际制成即可单独点亮，按自己的条目规则结算。一次制作可同时点亮原料和成品，各按稳定条目 ID 去重。操作成功后的库存、来源、条目和余额一起保存。

**一旦点亮，永久保留。** 名称、图像、描述、首次收录时间、已获品质和途径随存档保留。即使原料用尽、植株冻死、跨季或遇霾，收集进度也保留。

如果某处世界修复采用收集门槛，统计该地区符合条件的唯一已点亮条目。具体门槛与修复表现另行定案。

### 4.3 首次上锚倒计时

1. **真正取得可用原料时开始。** 未点亮的源条目，从第一份能投入其指定使用线的源原料取得成功时起算。需要收下鸡蛋才能做蛋羹时，收蛋那刻才开始；余绪复原只给种源，等取得可用的收成才开始。背包满时等实际领入背包再起算。同一条目同时只开一轮，期间新取得的合格原料归入本轮，截止时刻保持原值。
2. **整个使用线须在截止前完成。** 料理以制成为准，营建以落成为准，指定委托以履约为准。中间加工品继承实际原料所属的轮次，多源配方逐条目判定。完工时刻严格早于截止，且实际消耗了该源条目本轮原料，才会首次上锚。物志条目显示剩余活动时间和可用的用途；加工界面提示当前批次是否有效，以及预计完工会不会超时。
3. **过期后可再次尝试。** 保留已发现、品质历史、库存和进行中的加工。超时完成的成品照常产出，按加工品册自己的规则收录；源条目仍待点亮，本轮原料及其半成品可以继续出售、留种或使用。重新取得一份合格的源原料可开启新一轮，旧批次继续保留原轮次。从仓库取回、搬运或加工旧批次都沿用它的原轮次。
4. **跟随游戏活动时间。** 倒计时按当前计时模式推进，午夜日结时停表，确认次日后续算。每个源条目的时长按至少一条在取得时可达的使用线配平，计入路程、完整加工和操作余量。柳湾首条用途的时长随开局配方一起试玩确定。[时钟季节与天气](时钟季节与天气.md)

## 5. 区域余绪与首次发现

区域表配置初始余绪点及显形条件，未收录也能出现。采集后保存待复原物；完成复原只取得种源并标记发现。取得可用收成时开启倒计时，在期限内完成首条使用线后点亮并发稿酬。首采余绪点的领取状态独立保存；稀有物种要有可再次取得合格产物的路径，以便超时后重试。暂时错过显形窗口可等下一次。

柳湾的芥菜余绪位于旧制盐台西侧。霾天在地图上显示「绪」，靠近后按 F 采集。可在当天或改日把背包里的余绪交给田记所「复原种源」，得到两粒芥菜种子。浇水后 320 活动分钟成熟。收获后才开始 480 活动分钟的首次上锚倒计时，按期用粗盐腌制可同时收录芥菜和盐渍芥菜。芥菜可留种，种子、作物和可留种库存均耗尽后，可在田记所补领一粒。

## 6. 稀有度与出现条件

不做单一"稀有度"字段，改为**条件组合**，条件越苛刻越稀有：

| 维度 | 取值来源 |
| --- | --- |
| 区域 | 所属地图 |
| 季节 | 自然出现或成熟的季节；栽培另看逐季生长倍率。自然可得季的统计口径见[时钟季节与天气](时钟季节与天气.md) |
| 天气 | 八种天气中的指定项 |
| 时段 | 昼 / 夜 / 特定小时窗 |
| 地形 | 水边 / 石地 / 林地 / 洞穴 / 高地 |
| 地脉 | 是否在脉上、月相 |
| 前置 | 需先解锁的工具、建筑或条目 |

**展示要求**：未获得的条目必须在物志里显示**已满足与未满足的条件**，而不是完全隐藏。这是收集体验的核心——玩家要能规划下一次尝试，而不是瞎撞。

## 7. 分册结构

物志首页有七个分册。每个收集对象只登记一个主册；区域页聚合同一批条目，可按区域、来源或用途筛选。全册按唯一条目标识去重，分别显示已点亮数与总数。区域开放仍用具体目标清单。

| 主册 | 分组示例 | 收录示例与归属边界 |
| --- | --- | --- |
| 植物 | 粮食、蔬菜、果树、纤维与花草 | 用收获物完成指定用途，如野莓制酱。可栽培的野莓即使在野外采到也归植物 |
| 养殖动物 | 家禽、家畜、其他饲养动物 | 如用实收羊毛织成布，点亮来源羊种。蛋、奶、羊毛展示在来源动物页，作为背包物品；蛋制成的成品可入加工品册 |
| 虫类 | 昆虫、其他小型节肢动物 | 如将捕获的虫用作饵完成一次有效施钓，同一虫种只计一条 |
| 矿物 | 矿石、晶体、宝石 | 将天然矿物用于指定冶炼或营建终点；制成的金属锭归加工品 |
| 鱼类 | 淡水、海水、洄游 | 如将实际捕获的鱼做成鱼干，按来源鱼种收录 |
| 采集物 | 野生菌、贝壳、漂木、天然材料 | 如用漂木建成指定设施。归入此册的是以采集为主要身份且未归其他专册的对象 |
| 加工品 | 料理、发酵品、染料与织物、冶炼与建材 | 首次实际制成指定成品。多条配方得到同一成品只登记一次 |

类别由内容表指定。余绪、种子等流程物品可关联目标条目；无需把每个背包物都做成收集任务。美术原型的颜色对照只是试色，同一种产物即使收出多种颜色，也只有一个物品标识、一个条目和一份首次奖励。

**解锁下一区的判定不使用百分比**，见[土壤与经济](土壤与经济.md)与区域表。每份主产物的留种单位与粒数见[留种机制](土壤与经济.md)。

## 8. 首区内容与待定事项

### 柳湾开局与首条使用线

春季开局，首作物为樱桃萝卜。成熟时小圆红根露出少许根肩，可作为田间采收提示。

- 菜畦播种并收获樱桃萝卜。
- 在旧制盐台旁采一份岩盐，用火灶熬成十二份粗盐，每份保留实际投入的岩盐批次。
- 在腌菜缸用一份樱桃萝卜和三份粗盐制成盐渍樱桃萝卜。完工时分别检查实际投入的萝卜与粗盐；混用多批粗盐时，只要其中有一份来自期限内的岩盐批次，岩盐即可上锚。符合条件的条目各发一次稿酬。
- 在河岸钓一条鲫鱼，加一份粗盐可在火灶炖一碗鲫鱼汤。按期完工可点亮鲫鱼。岩盐的指定用途仍在腌菜缸完成。粗盐和鲫鱼汤各自在首次制成时收录进加工品册，无独立稿酬。

岩盐的上锚时限随开局试玩校准，计入播种后先去采盐、再等萝卜成熟并腌完的时间。

### 第一卷归档后

田记所的委托簿可领两粒小白菜种子。种子耗尽且田里与库存也没有小白菜时可以补领。浇水后试值为 360 活动分钟成熟，每株收一份，每份可留两粒种子。

小白菜收获入包时起算 480 活动分钟。用一份小白菜和三份粗盐在腌菜缸加工 75 活动分钟，成品继承投入小白菜的批次时限。首次制成盐渍小白菜单独收录并结稿酬 30 文，在截止之前把有效成品交作南山道行粮，才点亮小白菜、结源条目稿酬 55 文，并开启山道。超时成品仍可出售，田记所试收小白菜 14 文一份、盐渍小白菜 30 文一份。

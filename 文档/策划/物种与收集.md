# 物种模型与物志收集

**状态**：v0.1 框架
**范围**：物种实体定义、收益结构、生长阶段、物志条目状态机、稀有度模型
**不包含**：具体物种清单（待图标方案稳定后另立物种表）

---

## 1. 种植作物按一株结算

**硬约束**：种植系统中的一株实例对应一株完整植物，不把它的不同部位拆成多个收获目标。

一株作物是"一个东西"。它地上部分和地下部分属于同一株，收获时一并结算，不是两个可以分别采集的对象。

由此推出的三条规则：

1. **不做「部位型条目」**。同一株作物的可食部分不产生独立收获动作。
2. **不做「先采叶、后挖根」的二段式收获**。收获是一次动作，一次结算。
3. **副产物在收获时同时获得**，不需要额外操作，也不占用额外时间。

**这条约束的理由**：物种表一旦允许拆部位，条目数会以部位数膨胀，而玩家的实际行为没有增加——只是多按几次按钮。收集的乐趣在于"见到新东西"，不在于"多一种获得方式"。

## 2. 收益结构

一次收获同时结算三类产出：

| 类型 | 说明 | 是否保证获得 |
| --- | --- | --- |
| 主产物 | 该物种的核心收获物，卖价与加工的主要原料 | 是 |
| 副产物 | 同株上的附带产出，随主产物一并获得 | 是，但数量受条件影响 |
| 概率产物 | 稀有掉落，受土壤匹配度、天气、地脉、月相影响 | 否，有概率表 |

**规则**：
- 作物副产物可以是库存材料；只有策划指定有独立收集意义的对象才有物志条目标识。
- 概率产物可以是独立物种（如某种菌、某种虫），也可以是材料
- 三类产出一次入包。库存按物品标识和品质堆叠。外观颜色只影响显示；同品质的两种颜色果实进入同一堆，可互换用于出售、留种、加工或交付。不同品质可以分堆，同享一条收集记录。

**数据结构骨架**（字段为约定，不含内容）：

```
species
├── id
├── name
├── family            # 科属，决定连作障碍与土壤偏好
├── lifecycle         # 生长档位：速生/常规/长程/跨季/多年生
├── growth            # 各阶段天数、适季、耐季
├── soil              # pH 偏好、养分消耗侧重
├── yield
│   ├── main          # 主产物：id、数量区间、品质上限
│   ├── byproduct[]   # 副产物：id、数量区间、触发条件
│   └── rare[]        # 概率产物：id、概率、加成来源
├── art               # 图标与阶段图引用（对齐美术规范）
├── entry             # 物志条目（见第 4 节）
└── tags              # 可上锚途径：料理 / 染色 / 饲料 / 建材 …
```

## 3. 生长阶段

阶段划分**直接沿用美术规范**，不另造一套：

| 阶段 | 用途 |
| --- | --- |
| 刚出土 | 可选帧，用于"已发芽"的即时反馈 |
| 幼苗 | 第一帧有辨识度的叶已展开 |
| 生长中期 | 至少出现一种可见结构变化（抽藤、分枝、分蘖、莲座扩张、拔高） |
| 田间成熟 | 可采收，果实连枝或根肩外露 |
| 背包收获物 | 重新取景，采收部位占画面主体 |

**跨阶段约束**：相邻帧必须保持主茎走向或基部位置，不允许跳变。多年生作物额外需要"休眠"帧（非适季时显示停滞状态，但仍在画面中）。

字段上，每个阶段对应一张图；`刚出土` 为可选，其余为必需。

## 4. 物志条目

### 4.1 条目结构

| 字段 | 说明 |
| --- | --- |
| 条目 id | 每个收集对象一个稳定标识。库存物品或养殖、捕获事件映射到该标识；色板不参与标识、进度、稿酬或上锚判定 |
| 分册 | 唯一主册，区域、获取方式和用途可多选 |
| 状态 | 未收录或已点亮，由首次收录记录决定 |
| 首次收录时间 | 用于稿酬结算 |
| 已获品质档位 | 位掩码，记录收到过哪几档 |
| 已上锚途径 | 位掩码，记录通过哪些方式被使用过 |
| 揭示文本 | 未获得时显示的线索，不是完整描述 |

### 4.2 点亮与永久保留

未收录时显示获取线索。玩家首次满足该条目的收录条件后，点亮条目，记录首次收录时间，并按条目规则结算一次首次稿酬。

**一旦点亮，永久保留。** 名称、图像、描述、首次收录时间、已获品质和已上锚记录随存档保留，收集数量只增不减。卖掉、用掉或交付最后一件物品，遇到霾天或跨日，均不会让已点亮条目变暗或消失。上锚记录玩家怎样使用物种，并用于世界叙事与修复条件的设计。

如果某处世界修复采用收集门槛，统计该地区符合条件的唯一已点亮条目。具体门槛与修复表现另行定案。

## 5. 区域余绪与首次发现

区域表配置初始余绪点及显形条件，未收录也能出现。采集后保存待复原物；完成复原取得该稀有种时首次点亮，并按规则发放稿酬。按存档记录点位领取状态，读档或跨日不会重复领奖。暂时错过显形窗口可等下一次。

## 6. 稀有度与出现条件

不做单一"稀有度"字段，改为**条件组合**，条件越苛刻越稀有：

| 维度 | 取值来源 |
| --- | --- |
| 区域 | 所属地图 |
| 季节 | 适季 / 耐季 / 非耐季 |
| 天气 | 八种天气中的指定项 |
| 时段 | 昼 / 夜 / 特定小时窗 |
| 地形 | 水边 / 石地 / 林地 / 洞穴 / 高地 |
| 地脉 | 是否在脉上、月相 |
| 前置 | 需先解锁的工具、建筑或条目 |

**展示要求**：未获得的条目必须在物志里显示**已满足与未满足的条件**，而不是完全隐藏。这是收集体验的核心——玩家要能规划下一次尝试，而不是瞎撞。

## 7. 分册结构

物志首页有七个分册。每个收集对象只登记一个主册；区域页聚合同一批条目，可按区域、来源或用途筛选。全册按唯一条目标识去重，已见与总数分别显示。区域开放仍用具体目标清单。

| 主册 | 分组示例 | 首次收录与归属边界 |
| --- | --- | --- |
| 植物 | 粮食、蔬菜、果树、纤维与花草 | 获得指定主产物或完成稀有种复原。可栽培的野莓即使在野外采到也归植物 |
| 养殖动物 | 家禽、家畜、其他饲养动物 | 首次取得可饲养个体。蛋、奶、羊毛展示在来源动物页，作为背包物品；蛋制成的成品可入加工品册 |
| 虫类 | 昆虫、其他小型节肢动物 | 首次捕获；即使用于养蜂或作饵，同一虫种仍有唯一条目 |
| 矿物 | 矿石、晶体、宝石 | 首次获得天然矿物；冶炼出来的金属锭归加工品 |
| 鱼类 | 淡水、海水、洄游 | 首次捕获；以后放进鱼塘或鱼缸仍沿用原条目 |
| 采集物 | 野生菌、贝壳、漂木、天然材料 | 首次取得。归入此册的是以采集为主要身份且未归其他专册的对象 |
| 加工品 | 料理、发酵品、染料与织物、冶炼与建材 | 首次实际制成指定成品。多条配方得到同一成品只登记一次 |

类别由内容表指定。余绪、种子等流程物品可关联目标条目；无需把每个背包物都做成收集任务。美术原型的颜色对照只是试色，同一种产物即使收出多种颜色，也只有一个物品标识、一个条目和一份首次奖励。

**解锁下一区的判定不使用百分比**，见[土壤与经济](土壤与经济.md)与区域表。

# 《物志》规则修订与验收

2026-11-22 · v0.2。用以下场景核对今后的游戏实现。目前可操作的页面是作物美术原型和独立时钟测试台。

| 场景 | 预期结果 | 主文档 |
| --- | --- | --- |
| 收获一株，把其中一份拿去做饭 | 主、副、概率产出先统一入包；出售、留种、加工、交付按实际数量扣减。背包满时清出空间可重试，产出稳定 | [土壤与经济](systems/土壤与经济.md) |
| 同一产物收出两种颜色 | 同品质合堆，只计一件收集对象。颜色对照用于检验美术，商品、任务、配方和稿酬均认同一标识 | [物种与收集](systems/物种与收集.md) |
| 用新档寻找稀有种，然后找回残目 | 区域初始余绪能完成首次发现，条目受损后另有恢复余绪入口。恢复保留原始首次记录 | [世界设定](世界设定.md) |
| 23:59 种下作物，走到次日 06:00 | 用时 1 活动分钟，触发 1 次换日，位置、在制品和植株保留。关闭十小时后重开，以存档时刻继续 | [时钟季节与天气](systems/时钟季节与天气.md) |
| 采野莓、捕鱼、收蛋、制果酱 | 野莓按植物收录，鱼入鱼类，蛋关联养殖来源，首次制成果酱登记加工品。相同条目跨区域只算一次 | [分册规则 §7](systems/物种与收集.md) |
| 成熟果留田跨风日、霜日 | 风后可采数量保持原值。未覆盖果实在霜日按物种改品质；暂停后真实时间再长也不触发，采收入包锁定品质 | [天气 §6](systems/时钟季节与天气.md) |
| 暂停后步进到次日、增加 1,000 文 | 显示次日 06:00，换日数增加 1，余额增加 1,000；恢复焦点时仍尊重手动暂停 | [时钟与钱币测试台](../prototype/时钟与钱币测试台.html) |
| 更换作物插画 | 更新资源清单即可替换同一阶段图。田间、背包和存档使用同一物品标识；形状、配色和资源版本可独立调整 | [美术规范](../prototype/物志作物与物品美术规范.md) · [加载方案](../docs/architecture/时钟与存档架构.md) |

首批种植循环接入后，记录正常流速下第一次辨认中期、收获、上锚和买地的实际游戏时长，用于修订种植和经济数值。
